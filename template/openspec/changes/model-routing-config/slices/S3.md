# S3 · session-decompose.py：收口对账 effort 与新角色

## 做什么

`template/.claude/hooks/session-decompose.py` 新增两个参数：`--expect-efforts` 与 `--turns`。角色判定新增 `fixer` 与 `executor-large`；这两个可选角色没派发时不算零覆盖。

规则原文见 `specs/route-audit-efforts/spec.md`（5 个 scenario），决策见 `design.md` D6。

## owns

- `template/.claude/hooks/session-decompose.py`
- `tests/test_route_audit_efforts.py`（5 条 strict-xfail 骨架已写好）

## 现有接口（本文件内）

- `AGENT_ROLE` / `LABEL_ROLE` / `PHASE_ROLE` / `ROLE_ORDER`。
- `workflow_agents(wf_dir)` 返回 `(label, phase, model, turns, wall, agentType)`。
- `audit_routes(agents, expect, alias_of)` 返回 `(bad, seen, missing, empty)`。
- `main()` 解析 `--expect-models`，要求同时有 `--workflow`。

## 怎么做（TDD：先跑 verify，看 5 条 xfail）

1. **采集 effort**：`workflow_agents` 多取一项 effort，即第一条带顶层 `effort` 字段的 assistant 行的值，没有就是 None，追加到元组末尾。调用方的解包同步。`tests/test_evidence_timeline.py` 不解包这个元组，不受影响。
2. **角色判定**：抽出 `role_for(label, phase, atype, expect, turns)`，顺序如下：
   1. `base = label` 去掉末尾的 `:retry`；`base == "fix"` 或以 `fix:` 开头 → `fixer`；
   2. `turns.get(base) == "large"` → `executor-large`；
   3. 否则沿用 `AGENT_ROLE.get(atype) or label_role(label) or PHASE_ROLE.get(phase)`；`AGENT_ROLE` 的 `slice-executor-large` 改为 `executor-large`；
   4. 结果是 `fixer` / `executor-large`，但 expect 里没有这个键时，回落到 `executor`。
3. **零覆盖**：`OPTIONAL_ROLES = ("fixer", "executor-large")` 不进 `missing`。`ROLE_ORDER` 扩为 5 个角色，打印「路由对账：✅ 一致（…）」时按此顺序列出已采样的角色，形如 `fixer=fable`。
4. **effort 对账**：
   - 新参数 `--expect-efforts`，需要 `--workflow`；`--turns` 是 JSON 对象，缺省 `{}`。
   - 所有 agent 的 effort 都为 None → 打印「  ⚠ 转录无 effort 字段，effort 对账跳过」，不判红。
   - 否则逐个比对（角色判定同上），不符的打印 `  ❌ <label> · <phase> · 期望 effort <want> · 实际 <got>`，并返回 `EXIT_ROUTE_MISMATCH`。
   - 某个 agent 的 effort 为 None 时，只跳过这一个。
5. 帮助文本与头注释补上两个新参数。
6. 去掉 5 个 xfail 标记；`tests/test_evidence_timeline.py` 的既有路由对账用例（3 角色）必须保持绿。
