### CLI

| 子命令 | 参数 | stdout | 退出码 |
|---|---|---|---|
| `show` | `[--change-dir D \| --openspec DIR] [--json]` | 人读表；`--json` 时为 `{"组.键": {"model","effort","source"}}`，共 10 项，`source` ∈ `repo` / `builtin` | 0；配置非法 2 |
| `pin` | `--change-dir D` | 打印钉住的 7 个键 | 0；配置非法或 `slices.json` 缺失 2 |
| `resolve` | `--change-dir D` | `{"models": {5 角色}, "efforts": {5 角色}}` | 0；未 pin 或不合法 3；环境覆盖 3；配置非法 2 |
| `get` | `<组.键> [--change-dir D \| --openspec DIR]` | `{"model","effort","source"}`，`source` ∈ `pinned` / `repo` / `builtin` | 0；未登记的键或配置非法 2 |

### 各子命令的细节

- **openspec 根**：`--openspec DIR` 优先；否则由 `--change-dir` 推出（`<D>/../..`）；都没有时为当前目录下的 `openspec`。配置文件是 `<openspec 根>/model-routing.json`，不存在时视为 `{}`。
- **pin**：写入 `routing = {"source": <配置文件相对 git 顶层的路径，或 "builtin">, "flight": {...}, "ship": {...}}`。其余顶层键原样保留，键序不变；`json.dumps(..., ensure_ascii=False, indent=2)` 后补一个换行。已钉的值不同时，往 stderr 提示「routing 已改，批准将过期，需重新批准」。
- **resolve**：
  - 先查 `ENV_OVERRIDES`，任一非空 → exit 3，stderr 点名变量，并说明它会覆盖派发时传入的值；
  - 再查 routing：缺失或不合法 → exit 3，stderr 写 `python3 .claude/hooks/model-routing.py pin --change-dir <D>`，并说明「pin 后计划工件已改，需重新批准」。
- **get**：
  - flight / ship 组的键：change 钉过的优先（`pinned`）；
  - 其余按 repo → builtin；
  - 环境覆盖只往 stderr 打警告，不阻断（D7）。
- **校验报错**：逐条列出，每条点名 `组.键`。规划期组名的报错含「规划期不进路由配置」；非模型名的报错含「只写模型名」。

## 怎么做（TDD：先跑 verify，看 9 条 xfail）

1. 写常量与 `load_config(root)` / `validate(cfg)`，返回错误列表。
2. 写 `effective(root)` → 10 键表，每项带 source。
3. 实现 4 个子命令，用 argparse 子解析器。
4. 去掉 9 个 xfail 标记，verify 全绿。
5. 只用标准库，兼容 Python 3.8+；头注释写用途与退出码（风格参照 `session-model.py`）。
