# S1 · gate-scope.json 的 inert 声明：形状、生效判定、三处复用

## 做什么

只改 `template/.claude/hooks/slice-gate.py`，实现 design D1、D2，以及 D3 里「运行时依赖图优先」那一半。规则原文：`specs/inert-paths/spec.md` 的前四条 Requirement，与 `specs/ship-rerun-decision/spec.md` 第一条里声明了 `inert` 的那个 scenario。

本片不做：选测复核里的静态核对与对账判红、`flight-doctor.py`（S2）；无图退路与预告（S3）；任何文档（S4）。

## 依赖的接口

无（wave 1，与 S4 并行，owns 不相交）。

## 怎么做

TDD：先确认 `tests/test_inert_paths.py` 的 7 条骨架是红的（strict xfail），再写实现。

1. **声明**（D1）：
   - `SCOPE_EXTRAS` 加 `"inert"`（放在 `blind` 之后），`SCOPE_EXTRAS_SHAPE["inert"] = "字符串数组"`；
   - `_scope_extras` 的缺省值加 `"inert": []`；`_scope_extra_ok` 现有逻辑已覆盖字符串数组，不用改。
2. **生效判定**（D2、D3），放在 `_is_bookkeeping` 附近，四个小函数：
   ```python
   def _never_inert(rel, ctx):
       """永不按 inert 处理的路径 → 类别文字 | None：测试路径（is_test_path）/ 全局文件（_global_file）/
       声明的 global / changes 根下 / 声明文件。"""

   def _inert_ctx(root, change_dir):
       """→ {"inert": [glob], "global": [glob], "changes_rel": <changes 根相对路径>, "decl": {三份声明文件的相对路径}}"""

   def _inert_paths(root, paths, ctx, anchor=None):
       """paths 中按 inert 生效的子集 → (set, 矛盾 [(路径, 测试文件)])。
       匹配用 fnmatch.fnmatchcase（与 global / blind 相同）；anchor 给了时，被任一测试文件依赖
       （deps 的值 ∪ 其 _shell_closure，与 _final_select 同口径）的路径不生效，记为矛盾。"""

   def _recon_anchor(root, change_dir, data):
       """对账用的锚点：与本计划同命令指纹（_anchor_key）、同分层指纹、测到依赖图的最新一条（_anchor_candidates 的第一个）；
       没有、或 gate.test 缺失、或取指纹出错 → None。"""
   ```
   再包一层给调用点用：
   ```python
   def _inert_drop(root, change_dir, data=None, recon=True):
       """→ (drop, ctx)；drop(delta, anchor=None) 返回去掉生效路径后的 delta。
       没声明 inert 时 drop 原样返回、不读锚点池。anchor 缺省用 _recon_anchor（recon=False 时不用）。"""
   ```
   - 声明文件 = `_decl_rels(root, change_dir)` 的两份加分层文件 `_tiers_path(change_dir)`。
   - 类别文字固定为「测试路径」「全局文件」「声明的 global」「changes 根下」「声明文件」，S2 的违规文本要用。
3. **接进三处**（D2 的表）：
   - `_final_fresh`：加可选参数 `data=None`；差集去掉记账文件后为空 → 新鲜；否则 `drop(其余)` 为空才新鲜。`cmd_ship` 调用处把已读的 `data` 传进去。签名里原有的三个位置参数不动。
   - `_final_reusable`：加可选参数 `drop=None`；严格 Δ 去掉记账文件后，再经 `drop`。`cmd_final` 在读 final 记录后取一次 `idrop, ictx = _inert_drop(root, args.change_dir, data)`，同树沿用与后面取锚点都用它。
   - `_pick_anchor`：加可选参数 `drop=None`；每个候选算出 Δ 后 `d = drop(d, cand)`，再比大小。`cmd_final` 取锚点处传 `drop=idrop`；`_baseline_anchor` 加同名参数并透传，`cmd_baseline` 传 `_inert_drop(root, args.change_dir, data, recon=False)[0]`；`final_forecast` 同样传。`_impacted_anchor` 与 `_builtin_report` 不传。
   - `_try_reuse`：在算 `other` 之前 `tdelta = _inert_drop(root, change_dir, data, recon=False)[0](tdelta)`；返回值里的 `files` 仍是完整 `delta`。
4. **运行时矛盾的警告**：`cmd_final` 取到锚点且声明了 `inert` 时，对 `pick[1]`（已过滤的 Δ）与 `pick[0]` 调一次 `_inert_paths`，把矛盾逐条加进 warnings：`inert 声明与依赖图矛盾：<路径> 被测试文件 <文件> 依赖，本次按依赖图处理`。
5. **不要碰**：`cmd_preflight` 的内容过期判定、`strict_delta`（lint / typecheck 沿用）、`_impacted_anchor`。
