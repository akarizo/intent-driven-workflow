# S4 · 脚本：test-tiers.py 的 run unit、canary、probe 扩展、check / render 部件形态

**做什么**：扩展 `template/.claude/hooks/test-tiers.py`：
- 新增 `run unit`（驱动）与 `canary`（金丝雀自检）；
- `probe` 增加 `--root` / `--adapter`；
- `check` 与 `render` 支持部件形态。

语义见 `specs/test-tiers-polyglot` 第六条 Requirement，design D4、D6、D7、D8（驱动）。

**owns**
- `template/.claude/hooks/test-tiers.py`
- `tests/test_tiers_parts_cli.py`

**依赖 S1 / S2 的接口**（见 `slices/_interfaces.md`）：
- S1：`tiers_is_parts`、`tier_parts`、`layer_matches`、`part_test_files`、`is_canary`、`parts_of`、`TIER_TEST_NAME_RE`、`TIER_DRIVER_CMD`；
- S2：`run_part`、`_read_probe`（含补前缀）。
- 已存在：`_load_tiers_file`、`run_test_gate`、`toplevel`、`git`。

**做法**
1. **TDD**：逐条去掉 `tests/test_tiers_parts_cli.py` 的 `XF` 标记，先红后绿；`tests/test_tiers_cli.py` 是护栏。
2. **`run unit [--part P] [--openspec-root DIR]`**：
   - 加载分层文件（缺失 / 不合法 → 退出 2），`tier_parts` 后按名字排序；
   - 逐个在 `<top>/<root>` 下用 shell 运行 `unit.cmd`，输出直通 stdout / stderr；
   - 结束打印 `部件 <P>：exit <N> · <秒>s`；
   - 全 0 退出 0，否则 1；`--part` 只跑一个，不存在 → 退出 2。
3. **`check`** 部件形态（简写不变）：
   - 文件来源同现在，`git ls-files --cached --others --exclude-standard`；
   - 去掉金丝雀文件后，「全仓测试文件」= 匹配 `TIER_TEST_NAME_RE` 或任一部件 `test_files`；
   - 逐个判：
     - `parts_of` 为空 → `不属于任何部件：<文件>`；
     - 多于 1 → `属于多个部件：<文件>（<部件、…>）`；
     - 恰 1 → 在该部件单元层与各区域里计数：0 → `未归层：<文件>`，>1 → `匹配多层：<文件>（…）`。
   - 有问题退出 1，否则打印「全部 N 个测试文件恰属一个部件、恰落一层」退出 0。
4. **`canary (--part P | --root DIR --adapter CMD --canary CMD) [--openspec-root DIR]`**：
   - `--part` 模式读分层文件（只做形状校验，sha 缺失也能读），取 `parts[P].unit.probe`；没有 `probe` → 退出 2。
   - **出题**：`token = secrets.token_hex(8)`，`d = tempfile.mkdtemp()`；在 root 下运行适配器，环境 `FLIGHT_UNIT_CMD = canary`、`FLIGHT_CANARY_TOKEN`、`FLIGHT_CANARY_DIR`、`FLIGHT_TIER_OUT`、`FLIGHT_JUNIT`（临时路径）。
   - **判定**：用 `_read_probe` 读记录。按用例名（最后一个 `::` 之后，去非字母数字、转小写）匹配 `flightcanarypure` / `file` / `proc` / `net` 前缀词。逐条核验 spec 列出的条件，令牌文件 `d/token` 不存在时文本含「落盘」。
   - **通过**：
     - `--part` 模式计算 `probe.cmd` 里每个能解析为仓库内文件的词（`shlex.split`，先按 root 再按顶层解析，realpath 落在顶层内且是文件）→ `{顶层相对路径: sha256}`；
     - 一个都没有 → 退出 2；
     - 写回 `probe.sha` 与 `probe.checked`（ISO 时间），`json.dump(..., ensure_ascii=False, indent=2)` + 换行，其余内容原样；
     - 打印通过摘要，退出 0。独立模式只打印。
   - **不通过**：stdout 逐条列出未满足的条件（每条一行），不写文件，退出 1。
   - 无论结果都删掉临时目录。
5. **`probe [--root DIR] [--cmd CMD] [--adapter CMD] [--json PATH]`**：
   - `--root` 缺省 `.`；
   - 有 `--adapter` 时按适配器契约在 root 下运行（可复用 `run_part`，构造临时部件 `{root, unit: {paths: ["**"], cmd, probe: {cmd: adapter}}}`）；
   - 否则内置 pytest 探针在 root 下运行；
   - 用例 id 与文件路径一律相对顶层，后续汇总、输出格式与现在相同。
6. **`render`**：`plan.tiers` 是部件形态时，落点所属层改为「部件/层」标签（如 `py/unit`、`go-db`）；单元层判定（有触碰或 ≥3 秒即问题）照旧。
7. 更新文件头注释：子命令清单与退出码约定（0 / 1 / 2 / 3）。

**verify**：`python3 -m pytest -q tests/test_tiers_parts_cli.py tests/test_tiers_cli.py tests/test_approval_gate.py`

**注意**
- 不改 `slice-gate.py`；发现 S1 / S2 接口不够用时，按切片纪律在门禁 JSON 里报 G6 交回规划。
- 只用标准库，兼容 Python 3.8。
- 守护测试做 mutation 自证：去掉 `canary` 里的「令牌文件落盘」检查，`test_canary_rejects_incomplete_adapter` 要变红。
