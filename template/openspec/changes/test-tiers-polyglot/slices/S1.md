# S1 · 判定器：部件形态的加载、校验、选择器解析与 G12

**做什么**：
- 让 `slice-gate.py` 认识分层文件的部件形态：形状校验、`list` 选择器解析、适配器 sha 核对；
- 实现 lint 的部件规则；
- 实现部件归属（恰属一个部件、恰落一层）与 G12。

语义见 `specs/test-tiers-polyglot` 第一、二条 Requirement，design D1–D4、D6（sha 部分）、D8（lint 附加）、D11。

**owns**
- `template/.claude/hooks/slice-gate.py`
- `tests/test_tiers_parts_plan.py`

**依赖**：无。叠在 test-tiers 之上，以下已存在：
- `TIER_FILE`、`TIER_NAME_RE`、`TEST_FILE_RE`；
- `_tier_shape`、`_load_tiers_file(path)`、`_load_tiers(change_dir)`、`_tiers_path(change_dir)`；
- `tiers_matching(path, tiers)`、`_lint_tiers(data, change_dir)`；
- `glob_match`、`globs_intersect`、`_nonblank`、`toplevel()`、`git()`。

**做法**
1. **TDD**：逐条去掉 `tests/test_tiers_parts_plan.py` 的 `XF` 标记，先红后绿。`test_shorthand_tiers_unchanged` 是护栏，始终须绿。
2. **常量**：
   - `TIER_DRIVER_CMD = "python3 .claude/hooks/test-tiers.py run unit"`；
   - `TIER_LIST_TIMEOUT = 60`；
   - `TIER_TEST_NAME_RE`：`TEST_FILE_RE` 之外另认 `*_test.go`、`*Test(s)?.java|kt`、`*IT.java|kt`、`*Test(s)?.cs`、`*_spec.rb`、`test_*.rb`、`*_test.rb`；
   - Rust 规则（部件 root 下 `tests/` 里的 `*.rs`）在归属函数里按 root 判，不进正则。
   - **不改 `TEST_FILE_RE`**。
3. **加载 `_load_tiers_file(path)`**：
   - 顶层有 `parts` → 走新的部件形态校验（只做**形状**，不跑命令、不算哈希），否则原样走简写校验；
   - `parts` 与 `unit` / `regions` 并存 → 一条 `tiers:` 错误，同时含 `parts` 与 `unit`；
   - 部件形态的字段集与规则逐条按 spec 第一条 Requirement；区域名全仓唯一（重复时点名区域名）；
   - `root` 的存在性检查在下一步做（需要顶层）。
   - 返回值形状保持 `(tiers | None, errors)`。
4. **新增函数**（签名供 S2–S4 使用，写进 `_interfaces.md` 由 integrator 刷新）：
   - `tiers_is_parts(tiers) -> bool`；
   - `tier_parts(tiers) -> {name: part}`：简写形态返回 `{"main": {"root": ".", "unit": tiers["unit"], "regions": tiers.get("regions") or {}}}`，部件形态原样返回 `tiers["parts"]`；
   - `tier_list(top, part, layer) -> set[str] | None`：
     - layer 有 `list` 时，在 `<top>/<root>` 下用 shell 运行，超时 `TIER_LIST_TIMEOUT`；
     - 每行去空白、去空行、补 root 前缀（root 为 `.` 时不补），返回顶层相对路径集合；
     - 失败抛 `RuntimeError(原因)`；
     - 同进程按 `(top, root, list)` 缓存；
     - layer 用 `paths` 时返回 None。
   - `layer_matches(top, part, layer, path) -> bool`：`paths` 用 `glob_match`；`list` 看集合成员。
   - `part_test_files(top, part, path) -> bool`：
     - 有 `test_files` → glob；
     - 否则 path 在 root 下（root 为 `.` 时恒真），且匹配 `TIER_TEST_NAME_RE`，或在 root 下的 `tests/` 里以 `.rs` 结尾。
   - `is_canary(tiers, path) -> bool`：匹配任一部件 `unit.probe.canary_files`。
   - `parts_of(top, tiers, path) -> [name]`：path 属于哪些部件（排除金丝雀文件后）。
   - `tier_adapter_errors(top, tiers) -> [str]`：
     - 部件形态下逐个有 `probe` 的部件：缺 `sha` 或 `checked` → `tiers: 部件 P 的探针适配器未自检（运行 test-tiers.py canary --part P）`；
     - `sha` 里每个路径重算 sha256，缺失或不符 → `tiers: 部件 P 的探针适配器 <路径> 哈希与自检记录不符（重跑 test-tiers.py canary --part P）`。
   - `tiers_matching(path, tiers)`：
     - 简写形态行为不变；
     - 部件形态下返回 `["unit"]`（若任一部件单元层命中）加上命中的区域名（排序），需要顶层时内部取 `toplevel()`。
5. **`_lint_tiers`**：
   - 简写形态代码路径一行不改；
   - 部件形态（`top = toplevel(change_dir)`）依次校验：
     - 每个 `root` 是 top 下存在的目录（不存在时点名 root 原值）；
     - 每个 `list` 能解析（失败点名部件名与 `list`）；
     - `tier_adapter_errors`；
     - `gate.test` 去空白后等于 `TIER_DRIVER_CMD`（文本含 `gate.test` 与驱动命令原文）；
     - 有 `gate.impacted` → 报错（含 `gate.impacted`）；
     - `gate.integration` / `integration_skip` / covers 表态规则复用现有逻辑，区域按全仓名字查；
     - `scenario_tests` 文件须被某部件单元层或已选区域命中，用 `layer_matches`。
6. **G12（`cmd_gate`）**：
   - 简写形态不变；
   - 部件形态下，对区间改动、仍存在、属于全仓测试文件的文件逐个判：
     - 「全仓测试文件」= 匹配 `TIER_TEST_NAME_RE` 或任一部件 `test_files`，且不是金丝雀文件；
     - `parts_of` 为空 → `G12 tiers: <文件> 不属于任何部件（补 test_files / 新增部件）`；
     - 否则在所属部件中，不在单元层、也不在任何已选区域 → `G12 tiers: <文件> 不在部件 <P> 的单元层或本 change 已选区域内`。
   - `tier_seconds(durations, tiers)` 在部件形态下也要能跑（G7 耗时归层用 `tiers_matching`），但 `parts` 分项留给 S3。

**verify**：`python3 -m pytest -q tests/test_tiers_parts_plan.py tests/test_tiers_plan.py tests/test_slice_gate.py tests/test_gate_checks_lint.py tests/test_final_impacted.py`

**注意**
- 简写形态与无分层文件的行为、输出、`plan_sha` 必须不变：`tests/test_tiers_plan.py` 全绿即护栏。
- 只用标准库，兼容 Python 3.8；`compileall` 绿。
- `_load_tiers_file` 只做形状校验，保证 `test-tiers.py canary` 能在 sha 缺失时读入文件（S4 依赖这一点）；sha 与 `list` 运行放在 lint / 门禁侧。
