# S5 · 文档：部件形态、两种契约、金丝雀与多部件发现

**做什么**：把部件形态写进用户可见的文档：
- `/test-tiers` 命令；
- schema tasks instruction；
- `opsx-propose` 命令与同名 skill（两者同改，禁漂移）；
- README；
- `CLAUDE.md.snippet`。

语义见 `specs/test-tiers-polyglot` 最后一条 Requirement，design 全文（尤其 D1–D8）。

**owns**
- `template/.claude/commands/test-tiers.md`
- `template/openspec/schemas/intent-driven/schema.yaml`
- `template/.claude/commands/opsx-propose.md`
- `template/.claude/skills/openspec-propose/SKILL.md`
- `README.md`
- `template/CLAUDE.md.snippet`
- `tests/test_tiers_parts_docs.py`

**依赖**：无（只写文档，接口以 spec / design 为准）。

**做法**
1. **TDD**：去掉 `tests/test_tiers_parts_docs.py` 的 `XF`，先红后绿。
2. **`/test-tiers` 命令**：
   - 文件形状一节加部件形态示例：`parts` / `root` / `test_files` / `paths` 或 `list` / `junit` / `probe`；
   - 说明两种形态的区别：简写不变，新字段只在部件形态，部件形态不走增量 final。
   - 步骤改为：
     1. `/opsx-mini` 留痕；
     2. **发现部件**：扫描 manifest 与 workspace 文件（`go.mod` / `go.work`、`package.json` / pnpm workspace、`pyproject.toml`、`Cargo.toml` workspace、`pom.xml` / `build.gradle` 等），列候选部件（子项目 × runner）；
     3. **逐部件调研并实测**：
        - 切法：`paths` 或 `list`；
        - junit 怎么出：`$FLIGHT_JUNIT` 或 `unit.junit`；
        - 纯度怎么测：pytest 走内置探针；其他语言写适配器（契约：执行 `FLIGHT_UNIT_CMD`，往 `FLIGHT_TIER_OUT` 写 JSONL）+ 金丝雀用例（四个命名、`FLIGHT_CANARY_TOKEN` / `FLIGHT_CANARY_DIR`、无令牌时跳过）；
        - 先用 `canary --root … --adapter … --canary …` 验证；
     4. `probe --root … [--adapter …]` 逐部件实测；
     5. 起草 → `render` 审批页，审批页列「未覆盖」清单：不命中内置命名、也没写 `test_files` 的语言 → 停下等人类批准；
     6. 批准后搬文件、写分层文件，逐部件 `canary --part P` 写 sha；
     7. 复核：`check` 全绿、`run unit` 全绿、各区域命令全绿；
     8. 收尾提示：部件形态下进行中 change 的 `gate.test` 改为 `python3 .claude/hooks/test-tiers.py run unit` 并重跑 baseline。
   - 「非 pytest 仓库」一节改写：有 junit 即可判 G10，有自检过的适配器即可判 G11，都没有才降级为警告。
   - 「门禁的分层耗时」一节补 `tier_sec.parts`。
   - 保留现有四个子命令与 `tier_sec` 的说明（`tests/test_tiers_docs.py` 是护栏）。
3. **schema tasks instruction**：在测试分层那段补一句：部件形态（顶层 `parts`）下 `gate.test` 必须等于 `python3 .claude/hooks/test-tiers.py run unit`，不得写 `gate.impacted`；骨架文件须落在某部件单元层或已选区域。
4. **`opsx-propose` 命令与 `openspec-propose` skill**：「写骨架前先定层」那条补同样一句（两个文件措辞一致）。
5. **README**：测试分层段落补「部件」（monorepo / 多语言）、驱动命令、`canary` 自检与 sha 锁定一两句。
6. **`CLAUDE.md.snippet`**：测试分层那条补「多语言 monorepo 用 `parts` 部件形态」。

**verify**：`python3 -m pytest -q tests/test_tiers_parts_docs.py tests/test_tiers_docs.py tests/test_template_docs.py tests/test_docs_iron_rules.py tests/test_gate_checks_docs.py tests/test_incremental_final_docs.py`
