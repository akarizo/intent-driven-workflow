# S2 · slice-gate.py 采集：逐用例结局与耗时进观测表

## 做什么

让 `template/.claude/hooks/slice-gate.py` 的三个测试入口把「本次实测」记进进程内观测表。只采集，不落盘，不读写账本文件——本片与 S1 并行，**不得**依赖 `test-ledger.py`。规则原文见 `specs/test-ledger/spec.md` 的「门禁的每次测试运行留下逐用例结局与耗时的观测」，决策见 `design.md` D2、D3。

## 依赖的接口

无。本片对外提供（S4 / S5 用）：

- `ledger_observations() -> list`：观测表的浅拷贝。
- 每条观测 `{"form": "nodeid" | "junit", "outcomes": {id: 结局}, "secs": {id: 秒}[, "tier": 层名]}`。
- `run_test_gate(...)["deps"]` 多一个键 `secs = {nodeid: 秒}`。

## 怎么做

TDD：`tests/test_ledger_capture.py` 的 4 条骨架现在是红的。

1. **观测表**（放在 `flight_lock` 那一组辅助函数附近）：
   - 模块级 `_LEDGER_OBS = []`；
   - `_ledger_observe(form, outcomes, secs, tier=None)`：追加 `{"form", "outcomes": dict(outcomes or {}), "secs": dict(secs or {})}`，`tier` 不为 `None` 时加 `"tier"`；整个函数体包在 `try` 里，任何异常都吞掉；
   - `ledger_observations()`：`return list(_LEDGER_OBS)`。
2. **依赖图插件**（`DEPS_PLUGIN` 字符串里的 `pytest_runtest_logreport` 与 `pytest_sessionfinish`）：
   - 新增模块级 `_secs = {}`；`pytest_runtest_logreport` 在 `_nested()` 判断之后、`_outcome` 之前，先算出与 `_nodes` 同一口径的仓库相对 nodeid（现有的 `key + sep + rest`），`key` 不为 `None` 时把 `getattr(report, "duration", 0.0) or 0.0` 累加进 `_secs`；其后的结局逻辑不变；
   - `pytest_sessionfinish` 在写 `{"node": …}` 记录之后，多写 `{"sec_node": nodeid, "sec": round(秒, 4)}`（按 nodeid 排序）。
   - ⚠ 记录的键必须叫 `sec_node`，不能复用 `node`：`_read_deps` 对带 `node` 的记录会当成结局记录。
3. **`_read_deps`**：认 `sec_node` 记录，同一用例多条取最大值（xdist 的主进程与 worker 各写一份）；返回的 dict 多 `"secs": {nodeid: 秒}`。其余键不变。`_deps_merge` 不用改（它重新组装 dict，不带 `secs`；区域运行各自已经上报过）。
4. **`_junit_cases(path) -> ({id: 结局}, {id: 秒}) | (None, None)`**（放在 `_junit_secs` 旁边）：id 为 `classname::name`；有 `failure` 子元素 → `failed`，`error` → `error`，`skipped` → `skipped`，其余 `passed`；`time` 解析成 `float`，解析不了就不记这条的耗时；文件不存在或 XML 解析失败 → `(None, None)`。
5. **`run_test_gate`**：在读完 `res["probe"]` / `res["deps"]` 之后、`if rc == 0:` 之前（仍在 `with tempfile.TemporaryDirectory()` 块内，junit 还在）加一处上报，**仅当 `cwd is None`**：
   - `res["deps"] is not None` → `_ledger_observe("nodeid", res["deps"]["nodes"], res["deps"].get("secs"))`；
   - 否则 `_junit_cases(junit)` 解析得出 → `_ledger_observe("junit", outcomes, secs)`；解析不出就不报。
   - `_plain=True` 的那次重跑走的是内层调用，内层自己会报，外层在 `return res` 处已经返回，不会重复。
6. **`_pytest_outcomes`**：
   - `env["FLIGHT_G7_SEC"] = sec_out` 改为恒设（原来只在 `durations` 是 dict 时设）；它上面那句 `env.pop("FLIGHT_G7_SEC", None)` 保留；
   - 读 `sec_out` 时先累加进本地的 `run_secs`，`durations` 是 dict 时照旧同步累加进去；
   - 读完后 `_ledger_observe("nodeid", dict(outcomes), run_secs)`（`outcomes` 是 `[(nodeid, 结局)]`）。超时或没有输出时 `outcomes` 为空，照报一条空观测即可。
   - 返回的四元组不变。
7. **`run_part`**：函数末尾返回前，`res["secs"]` 不为 `None` 时 `_ledger_observe("nodeid", {}, res["secs"], tier="unit")`。注意函数里有两处 `return res`（探针有记录时提前返回、末尾返回），两处都要报，各报一次。`run_part` 内部经 `run_test_gate(..., cwd=cwd)` 的那次因为带 `cwd` 不会重复上报。
8. 文件头的子命令说明不用动；在 `run_test_gate` 的文档串里补一句 `deps` 多了 `secs`。

## 不要做

- 不读写 `test-ledger.py`，不写任何文件。
- 不改 `_anchor_forward`、`_write_test_result`、任何判定与文本。
- 不给 `_deps_merge` 加 `secs`。

## 解锁

去掉 `tests/test_ledger_capture.py` 四个用例的 `@PENDING`，`PENDING` 不再使用时连同定义与 `import pytest` 一起删除。MUST NOT 改断言与函数名。verify 里其余文件不在本片 owns 内，必须保持全绿——它们是「返回值含义不变」的护栏（在一次性原型上已确认这些改动不会让它们变红）。
