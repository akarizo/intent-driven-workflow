# S6 · flight-doctor.py doctor 新增 [tests]

## 做什么

给 `template/.claude/hooks/flight-doctor.py` 的 `doctor` 加一节 `[tests]`：最近一份账本的各层用例数与耗时、最慢用例、无耗时条数，以及最近几个 change 的测试变更。规则原文见 `specs/test-ledger/spec.md` 的「体检列出测试账本」，决策见 `design.md` D11。

只读；`doctor` 恒以 0 退出的约定不变；其余各节的输出一个字都不改。

## 依赖的接口

见 `slices/_interfaces.md` 的 S1、S3 两节：

- `test-ledger.py`：`load(root, change, name)`（读账本）、`summary(ledger)`、`parse_segment(note)`（从时间线备注取回 `{"added", "removed", "added_sec"}`，没有片段返回 `None`）。
- 本文件已有：`_load(mod_name, file_name)`（按路径加载同目录模块）、`_changes(openspec_root)`（在途 change 的 `[(名, 目录)]`）、`_err(e)`。

## 怎么做

TDD：`tests/test_flight_doctor_tests.py` 的 3 条骨架现在是红的（输出里没有 `[tests]`）。

1. `load_ledger()`：`_load("test_ledger", "test-ledger.py")`，与 `load_lock()` 并列。
2. `doctor_tests(openspec_root, changes) -> [str]`，首行固定是 `[tests]`，放在 `doctor()` 里**最后一节**（`[lock]` 之后）：
   - 仓库根：`git -C <openspec_root> rev-parse --show-toplevel`（可借 `load_gate().git`，或直接 `subprocess`）；取不到 → 一行 `  不在 git 仓库，跳过`。
   - **选账本**：对每个在途 change 读 `final` 与 `baseline` 两份，取 `at` 最大的一份；`at` 相同时 final 先于 baseline。
   - **有账本**时依次打印（缩进两格）：
     ```
       账本：<change> · <phase> · <commit 前 10 位> · <mode>
       <层>：N 条 · X.X 秒            ← summary 的 tiers 每层一行；没有层的那组显示为「未分层」
       无耗时 N 条                    ← N 为 0 也打印
       最慢：
         X.XXXs  <用例 id>（<层>）    ← 按耗时由大到小，至多 10 条；没有带耗时的用例时这一组不出
     ```
   - **没有任何账本**：`  没有账本数据：本机还没有带账本的 baseline / final（升级后重跑一次 baseline 即有）`。
   - `openspec_root` 下没有 `test-tiers.json` → 再加一行 `  未配置测试分层：账本不分层；跑 /test-tiers 划分后才有各层数字`（有没有账本都打印）。
   - **最近的测试变更**：对每个在途 change 读 `timeline.md`，取最后一条事件为 `final` 且 `parse_segment(备注)` 不为 `None` 的行；按该行时间由新到旧取至多 5 个，打印：
     ```
       最近的测试变更：
         <change>：用例 +A/-R（新增 X.Xs）
     ```
     一个都没有时这一组不出。
   - `test-ledger.py` 加载失败或读账本抛错 → 该节只有一行 `  test-ledger.py 不可用：<原因>`（照 `[lock]` 节对 `flight-lock.py` 的处理）。
3. `doctor()` 里用 `try` 包住，照现有各节的写法。文件头注释的 `doctor` 一行把节名补上 `[tests]`。

## 注意

- 骨架按子串断言：`"unit" in l and "12 条" in l and "3.0" in l`、`"无耗时 1 条" in l`、含 `::` 的行就是最慢清单（所以除最慢清单外别的行不要出现 `::`）、最近变更的行里要同时有 change 名、`+A/-R` 与新增秒数。
- `tests/test_flight_doctor_tests.py::test_doctor_tests_explains_missing_ledger` 要求 `[runner]`、`[anchors]`、`[gate.test]`、`[declare]`、`[checks]`、`[lock]` 六个节标题各自独占一行，照旧输出。
- 「在途 change」沿用 `_changes()` 的口径（不含 `archive/`）。
