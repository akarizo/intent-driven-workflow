# S1 · test-ledger.py：账本合成、存取与 show

## 做什么

新建 `template/.claude/hooks/test-ledger.py`（只用标准库，兼容 Python 3.9）：把门禁的观测合成一份逐用例账本，存到 git common dir，并提供只读的 `show` 子命令。规则原文见 `specs/test-ledger/spec.md` 的「账本由实测与沿用合成，存在 git common dir」，决策见 `design.md` D1、D2、D4–D6。

本片不依赖任何其他切片：测试直接喂观测与来源的字面量。对账（`delta` / `segment` / `render` / `advice`）是 S3 的事，本片不要写。

## 依赖的接口

无。输入的形状由本片定下，S2 / S4 / S5 照此喂：

- **观测** `{"form": "nodeid" | "junit", "outcomes": {id: 结局}, "secs": {id: 秒}[, "tier": 层名]}`。结局可能是大写（`PASSED` / `XFAIL` / `XPASS` …）或小写。
- **全集** `universe = {nodeid: 结局}`（新锚点的 `nodes`，已是小写）。
- **来源** `{"cases": {id: {"o": 结局, "s": 秒 | None}}[, "id_form": "nodeid" | "junit"]}`——上一份账本本身就满足这个形状。

## 怎么做

TDD：`tests/test_ledger_core.py` 的 5 条骨架现在是红的（`load_hook("test-ledger")` 找不到文件）。

1. 常量：`LEDGER_DIR = "flight-ledger"`、`KEEP_CHANGES = 30`（草案值，注释里标明）。
2. `build(meta, observations, universe=None, source=None, rerun_files=None, root=None, tier_of=None) -> dict`：
   - **选 id 形式**：给了 `universe` → `nodeid`；否则观测里有 `junit` 形式，或 `source.get("id_form") == "junit"` → `junit`；否则 `nodeid`。
   - **并观测**（按列表顺序，后来的覆盖先前的）：
     - 账本是 `nodeid` 形式 → 只并 `nodeid` 形式的观测；
     - 账本是 `junit` 形式 → `junit` 形式的原样并入；`nodeid` 形式的先换算：`a/b/test_x.py::C::t[p]` → `a.b.test_x.C::t[p]`（文件路径去掉 `.py`、`/` 换成 `.`，中间各段以 `.` 相连得 classname，最后一段是 name）。
   - **用例集合**：给了 `universe` → 它的键；没给 → 实测到的；`rerun_files` 不为 `None` 时再并上来源里「所在文件在 `root` 下仍存在、且不在 `rerun_files` 里」的用例。
     - `junit` 形式用例的文件：把 classname 按 `.` 拆开，从长到短试 `<前 n 段以 / 相连>.py` 在 `root` 下是否存在，取第一个存在的；`root` 为 `None` 时取最长的那个。`nodeid` 形式的文件就是第一个 `::` 之前的部分。
   - **每条用例** `{"o", "s", "t", "m"}`：
     - 实测到的 `m = 1`，`s` 取观测（保留 3 位小数；观测里没有它的耗时 → `None`），`o` 取 `universe`（给了时）否则取观测；
     - 其余 `m = 0`，`o` 取 `universe`（给了时）否则取来源，`s` 取来源；来源没有这条或没有耗时 → `None`。**不得填 0、不得估算**。
     - 结局统一小写：`XFAIL → xfailed`、`XPASS → xpassed`，其余转小写；空 → `None`。
     - `t`：该用例来自带 `tier` 的观测 → 取它；否则 `tier_of` 不为 `None` 且能定出文件 → `tier_of(文件)`；否则 `None`。
   - **顶层**：`dict(meta, v=1, id_form=…, tiered=…, complete=…, cases=…)`。`tiered` = 给了 `tier_of` 或有观测带 `tier`。`complete` = 每条 `m = 0` 的用例都在来源的 `cases` 里；`rerun_files` 不为 `None` 而 `source` 为 `None` → `False`。
   - `cases` 按 id 排序。
3. `from_anchor(anchor) -> dict | None`：`anchor["nodes"]` 是 dict → `{"cases": {n: {"o": o, "s": secs.get(n)}}, "id_form": "nodeid"}`（`secs` 取 `anchor.get("secs")`，不是 dict 就当空）；否则 `None`。
4. `secs_of(ledger) -> dict | None`：`{id: s}`，只含 `s` 不为 `None` 的；`ledger` 为 `None` → `None`。（S4 / S5 写锚点用。）
5. `summary(ledger) -> {"cases", "measured", "inherited", "no_sec", "id_form", "complete", "tiers": {层: {"cases", "sec"}}}`：没有层的归在 `"-"`；`sec` 是该层耗时之和（`None` 不计），保留 1 位小数；层没有用例就不出现。
6. 存取：
   - `ledger_dir(root) -> str`：`git rev-parse --git-common-dir`（在 `root` 下运行；相对路径拼回 `root`）下的 `flight-ledger`；不在 git 仓库 → `RuntimeError`。
   - `save(root, change, name, obj) -> str`：原子写（同目录临时文件 + `os.replace`）`<ledger_dir>/<change>/<name>.json`，返回路径；写完清理：按「目录内最新文件的修改时间」只留最近 `KEEP_CHANGES` 个 change 目录，其余整目录删掉（删不掉忽略）。
   - `load(root, change, name) -> dict | None`：读不到、不是 JSON 对象、不在 git 仓库都返回 `None`。
7. CLI（`main(argv=None)`，`argparse` 子命令）：
   - `show --change-dir DIR [--phase baseline|final] [--tier 层] [--top N] [--json]`：change 名取 `DIR` 的目录名，仓库根取 `git -C DIR rev-parse --show-toplevel`；`--phase` 缺省先 `final` 后 `baseline`。
   - `--json` → `{"summary": …, "cases": [{"id", "o", "s", "t", "m"}, …]}`，用例按耗时由大到小（`None` 排最后，同耗时按 id）；`--tier` 只留该层，`--top` 只留前 N 条。
   - 文本输出：首行来源（change、阶段、commit 前 10 位、模式），随后每层一行「<层>：N 条 · X.X 秒」，再逐条「<秒>s  <id>（<层>）」。
   - 退出码：0 有账本；1 没有（打印含「没有账本」的一行）；2 `DIR` 不存在或不在 git 仓库。
8. 文件头注释照 `flight-lock.py` / `flight-doctor.py` 的写法列出 CLI 与模块级函数；写明「只读 / 只写 git common dir，不改仓库文件」。
