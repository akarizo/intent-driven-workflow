# S5 · slice-gate.py final 落账与「测试变更」输出

## 做什么

让 `slice-gate.py final` 在真的跑了测试套件时写收口账本、与基线账本对账，并把结果放进四处：输出 JSON 的 `tests`、时间线片段、`delta.json`、`ship --markdown` 的「## 测试变更」。同时补上部件形态（baseline 与 final 两处）的落账。规则原文见 `specs/test-ledger/spec.md` 的「final 写收口账本并报告测试变更」，决策见 `design.md` D6–D10。

全部只报告：`ok`、`failed`、退出码与没有账本功能时相同。

## 依赖的接口

见 `slices/_interfaces.md` 的 S1、S3、S4 三节：

- S4 `slice-gate.py`：`_ledger_mod()`、`_ledger_commit(root, name, meta, tiers, universe=None, source=None, rerun_files=None)`、`_ledger_secs(led)`。
- S1 / S3 `test-ledger.py`：`from_anchor`、`summary`、`load`、`save`、`delta(base, final, rerun_files=None, root=None)`、`segment(d)`、`render(d)`。

## 怎么做

TDD：`tests/test_ledger_final.py` 的 6 条骨架现在是红的。

1. **`cmd_final` 的落账点**。只在「本次确实跑了套件」时落账：`v7` 为空、`sfail` 为空、且走到了下面五个分支之一。`meta = {"commit": head, "phase": "final", "mode": …, "lock": hold.info.get("state")}`。

   | 分支 | `mode` | `universe` | `source` | `rerun_files` | 位置 |
   |---|---|---|---|---|---|
   | 部件形态（`tiers_is_parts`） | `parts` | `None` | `None` | `None` | `_final_parts(...)` 返回之后 |
   | `gate.impacted` | `impacted` | `None` | `None` | `None` | 该分支末尾 |
   | 无图退路（`tonly is not None`） | `tests-only` | `None` | 本 change 上一份 `final.json`，`commit` 等于 `tonly[0]["commit"]` 才用，否则 `None` | `inc["rerun"]` | 同下（该分支的 `anchor_part` 是 `None`） |
   | 内建增量 | `incremental` | `anchor_part["nodes"]`（`nodes_ok` 为真时，否则 `None`） | `from_anchor(pick[0])` | `inc["rerun"]` | 区域跑完之后、`_anchor_write` 之前 |
   | 全量 | `full` | `anchor_part["nodes"]`（`nodes_ok` 为真时，否则 `None`） | `None` | `None` | 区域跑完之后、`_anchor_write` 之前 |

   - 无图退路的来源账本要在落账（覆盖写 `final.json`）之前用 `load(root, name, "final")` 读出；该分支不写锚点，不涉及 `secs`。
   - 后四个分支共用「区域循环之后、`if cur_snap is not None and anchor_part is not None:` 之前」这一个位置即可（`gate.impacted` 与无图退路两个分支的 `anchor_part` 是 `None`，同一位置也能覆盖）。
   - 写锚点的 `dict(anchor_part, …)` 加 `secs=_ledger_secs(led)`。
   - 同树沿用在函数开头就返回了，天然不落账；G7 红与选测复核未过时跳过落账。
2. **对账与输出**（落账成功、拿到账本 `led` 时）：
   - `base = load(root, name, "baseline")`；`d, why = delta(base, led, rerun_files, root)`（`rerun_files` 与落账时相同）；
   - `result["tests"] = dict(summary(led), delta=d, why=why)`；
   - `d` 不为 `None` 时：`save(root, name, "delta", d)`；时间线片段 `segment(d)` 插在 `segs` 里「检查」片段之后、`_lock_note(...)` 之前；
   - 对账与存盘同样包在 `try` 里：出错 → `result["tests"]["delta"] = None`、`why` 写原因，不插片段；
   - 落账返回的警告追加进 `warnings`。没有落账的 final（上面三种不跑套件的情形、账本模块不可用）输出里**没有** `tests` 键。
   - `summary` 文本、`result["summary"]` 不动。
3. **部件形态的 baseline**（S4 留下的那一格）：`cmd_baseline` 的落账点在 `parts` 为真时也落账，`mode = "parts"`，其余参数都是 `None`；`bl["ledger"]` 同样写摘要。部件形态不写锚点，所以不涉及 `secs`。
4. **`cmd_ship` 的 `--markdown`**：
   - 取 `report_latest(args.change_dir).get("final")`（slices.json 不存在时没有这一步，按没有处理）；
   - `load(root, <change 名>, "delta")` 读到、且 `str(它的 commit)[:10] == final 行的 commit` → 在 `parts` 列表末尾追加 `render(delta)`；
   - 账本模块不可用、读不到、对不上、任何异常 → 不追加，输出与现状相同；
   - 不带 `--markdown` 的 JSON 输出、退出码、`timeline_record(…, "ship", …)` 都不动；文档串里把「只读 gate-report.md、HEAD、review-findings.json」补成另读 `delta.json`（只用于 `--markdown`）。
5. **钉键的旧测试**：`tests/test_gate_checks_baseline.py::test_no_checks_behavior_unchanged` 里 final 输出键的白名单加上 `"tests"`。只加这一个词，别的断言不动。
6. 文件头注释里 `final` 与 `ship` 的说明各补一句。

## 注意

- `tests/test_ledger_final.py::test_final_full_reports_test_delta` 要求片段前面有「测试 Xs」、后面还有别的片段（锁片段），且 `flight-doctor.py cost` 的结果不受影响——片段文本一律用 `segment(d)` 的返回值，不要自己拼。
- `test_parts_runs_write_ledger`：部件 `sh` 的用例 id 是 `sh::sh::TestS`，没有文件路径，层来自 S2 上报时带的 `tier = unit`；部件 `py` 的用例 id 是顶层路径 `svc/py/tests/unit/test_p.py::test_ok`。两次运行用例相同，对账新增与删除都是 0。
- `test_ledger_failure_does_not_fail_final` 用不含 `test-ledger.py` 的 hooks 副本：`warnings` 里要有一条以「测试账本未写」开头，输出没有 `tests`，时间线没有「用例 +」。
- `tests/test_ship_verdict.py::test_ship_markdown_empty_when_ready` 钉住「ready 时 `--markdown` 输出为空」：那个用例的仓库里没有 `delta.json`，行为不变，必须保持全绿。
- `test_tests_only_final_inherits_previous_final_ledger`：夹具来自 `tests/test_final_tests_only.py` 的 `_nograph`（第一次 final 是全量，账本是 junit 形式的 3 条）；第二次 final 走无图退路，重跑的观测是 nodeid 形式，按 D2 正向换算并入 junit 形式的账本；与基线账本对账新增 1 条（`tests.test_a::test_a_again`）。
- `tests/test_final_tests_only.py` 钉住无图退路的输出、时间线备注开头（「增量（无图」）与结果文件，不在本片 owns 内，必须保持全绿。
- 本片是三个 wave 里最后改 `slice-gate.py` 的一片；`gate`（切片门禁）不落账，不要给它加调用。
