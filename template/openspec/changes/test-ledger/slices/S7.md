# S7 · 文档：测试账本与「测试变更」

## 做什么

把测试账本写进四份文档。规则原文见 `specs/test-ledger/spec.md` 的「文档说明测试账本与测试变更」；行为的权威描述在 `design.md` D2、D4–D9、D11（写文档时以它为准，不要自己发明字段）。

本片只改文档与自己的测试，不依赖其他切片（文档描述的子命令由 S1 / S3 提供；本 change 没有改 agent 定义与工作流脚本，文档先于实现合回不会影响飞行）。

## 依赖的接口

无。

## 怎么做

TDD：`tests/test_ledger_docs.py` 的 2 条骨架现在是红的。

1. **`template/.claude/flight-runner-contract.md`**：在第 8 节之后新增 `## 9. 测试账本`（标题里必须有「测试账本」四个字，以 `## 9.` 开头）。原有第 1–8 节的标题一个字都不能动。正文按本仓文档的密集写法，至少写明：
   - **是什么 / 在哪**：baseline 与 final 每次跑测试都留一份逐用例账本，放 `<git common dir>/flight-ledger/<change>/`，三份文件 `baseline.json` / `final.json` / `delta.json`，不进仓库，只保留最近 30 个 change；
   - **每条用例四个字段**（表格）：`o` 结局、`s` 秒（取不到为 `null`，不估算）、`t` 层（`unit` / 区域名，没有分层文件为 `null`）、`m`（1 本次实测 / 0 沿用）；
   - **耗时的来源**：依赖图测到 → 依赖图插件（nodeid）；没测到 → junit 的 `time`（`classname::name`）。包装脚本只要按第 1 节转发 `$FLIGHT_PYTEST_ARGS` 里的 `--junitxml` 就有耗时；
   - **沿用**：增量运行里没重跑的用例沿用锚点的结局与耗时；升级前写的锚点没有耗时，记 `null`，跑一次全量后补齐；
   - **看账本**：`python3 .claude/hooks/test-ledger.py show --change-dir <dir> [--phase …] [--tier …] [--top N] [--json]`；`python3 .claude/hooks/test-ledger.py delta --change-dir <dir> [--markdown|--json]`；
   - **测试变更**：final 与基线对账——新增、删除、变慢、各层前后；出现在 final 输出 JSON 的 `tests`、时间线片段 `用例 +A/-R（新增 Xs）`、PR 正文的「## 测试变更」；
   - **只报告**：账本与对账不判红；账本写不成只留一条「测试账本未写」警告，不影响门禁结论；
   - **已知限制**：切片门禁不留账；部件形态只有单元层、没有部件维度；账本只在产生它的机器上。
   - 骨架按子串断言，第 9 节正文里必须出现：`flight-ledger`、`test-ledger.py show`、`test-ledger.py delta`、`null`、`沿用`、`不判红`。
2. **`template/.claude/commands/test-tiers.md`**：在「## 门禁的分层耗时」一节末尾加一条，写明测试账本按分层文件给每条用例归层、没有分层文件时账本不分层，并指向契约第 9 节。骨架要求**同一行**里同时有「测试账本」与「分层文件」。
3. **`template/.claude/commands/pr-ship.md`**：在起草正文那一步，贴 `slice-gate.py ship --change-dir … --markdown` 输出的那一条里补充——输出还可能含「## 测试变更」一节（本次 final 的对账结果，ready 时也可能有），原样贴入，不改写、不删减。骨架要求：从含 `slice-gate.py ship --change-dir` 与 `--markdown` 的那一行起 7 行之内，有一行同时含 `## 测试变更` 与「原样」。现有那句「输出非空时追加到正文（…）。不要自己改写或删减 reasons。」保留。
4. **`README.md`**：在「全机测试锁」那一条附近加一条，**同一行**里同时有「测试账本」与 `[tests]`，说明 baseline / final 留逐用例账本、收口打印测试变更、`flight-doctor.py doctor` 的 `[tests]` 可看，细则见契约第 9 节。
