## 接口约定（S2 / S3 依赖）

- `REGISTRY["cleanup"] = ("runner",)`，`BUILTIN["cleanup.runner"] = {"model": "sonnet", "effort": "low"}`（复用 `_SONNET_LOW`）。`cleanup` **不**进 `PINNED_GROUPS`。
- 模块常量 `FORK_COMMANDS = {"cleanup.runner": "clean-after-merged.md"}`：fork 命令的唯一登记处，S3 的测试用 `load_hook("model-routing").FORK_COMMANDS` 读取。
- CLI：`model-routing.py frontmatter [--check] [--openspec DIR] [--commands DIR]`
  - `--commands` 缺省为 `Path(__file__).resolve().parent.parent / "commands"`；`--openspec` 沿用 `openspec_root(args)`（缺省 `./openspec`）；
  - 写模式 exit 0，每个命令打印一行 `<文件名>  <model> · <effort>`；
  - `--check`：一致 exit 0（打印一行「frontmatter 与路由一致」）；漂移逐条打印 `<文件名>：<字段> 期望 <x> 实际 <y>`，exit 1，不写；
  - 配置非法 / 文件缺失 / 首个 `---` 块里没有 `context: fork` 行 → `die(EXIT_INVALID, …)`（exit 2），不写任何文件。先全部校验、再统一写，保证「不写任何文件」。

## 怎么做（TDD：先跑 verify，看 5 条 xfail）

1. 注册表：加 `cleanup` 组与 `BUILTIN` 项、`FORK_COMMANDS`；更新文件头「用法」注释，补上 `frontmatter` 一行；把 `effective` 的 docstring 里「10 键表」改为「11 键表」。
2. `tests/test_model_routing.py::test_routing_builtin_defaults_without_config`：`len(table) == 10` 改为 11，GWT 注释里的「10 个键」同步改。这是钉住键数的旧测试，必须在本片改。
3. 新增 `cmd_frontmatter(args)`：
   - 用 `re.match(r"^---\n(.*?)\n---\n", text, re.S)` 取块，没有块按非 fork 处理；
   - 块内逐行处理：以 `model:` / `effort:` 开头的行替换为 `model: <m>` / `effort: <e>`，缺的追加到块末（先 model 后 effort）；
   - 块外与块内其他行逐字保留，换行风格不变；
   - 判 fork：块内有一行 `strip()` 后等于 `context: fork`。
4. `main()` 注册子命令：`--check`（store_true）、`--openspec`、`--commands`。
5. 去掉 `tests/test_routing_frontmatter.py` 的 5 个 xfail 标记，verify 全绿。
