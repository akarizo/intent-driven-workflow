# S1 · `takeoff-gate.py` 认会话 `/goal` 与 human 来源的 `queued_command` 插话

## 做什么

给起飞门禁加两项判据，规则原文见 `specs/goal-takeoff-authorization/spec.md` 前两条 Requirement，决策见 `design.md` D1–D5：

1. **会话 goal 生效**：在转录主链上按文件顺序找最后一条 `goal_status` 附件。它的 `met is False` 时，批准成立，豁免新鲜度。
2. **人类中途插话**：`queued_command` 附件满足 `origin.kind == "human"` 且 `commandMode == "prompt"` 时，按人类消息判定。

CLI 模式与 hook 模式都经过 `verdict()`，只改这一处判定链，两种模式就同时生效。本片只改脚本和本片的测试文件，不改任何文档。

## 怎么做（`template/.claude/hooks/takeoff-gate.py`）

1. **读转录只读一次**：抽出 `load_rows(path)`，返回按文件顺序排列、已 `json.loads` 的行列表，坏行跳过。`latest_approval` 与新增的 `active_goal` 都从它取数据，不要读两遍文件。
2. **新增 `active_goal(rows)`**，返回 `(datetime, 摘要)` 或 `None`：
   - **只看主链附件**：`row["type"] == "attachment"`、`row.get("isSidechain")` 非真、`(row.get("attachment") or {}).get("type") == "goal_status"`。
   - **逐行记录两个值**：
     - `last`：最后一条这类附件；
     - `since`：最后一条同时满足 `met is False` 与 `sentinel` 为真的附件（即设立事件）的时间。
   - **生效判定**：`last` 存在且 `last["attachment"].get("met") is False` 才算生效。`met` 缺失或是 `None`，都不算生效。
   - **证据时间**：用 `since`。`since` 是 `None`（转录被截断）时，退用 `last` 的时间。
   - **时间取法**：先用 `parse_ts(row.get("timestamp"))`；取不到再用附件内的 `timestamp`；两者都取不到，跳过这一行。
   - **摘要**：`summarize("/goal " + (condition or "").strip())`，沿用 40 字截断。
3. **`human_text(row)` 加附件分支**，`user` 分支保持不变：
   - **判定条件**：`row["type"] == "attachment"`，`isSidechain` 非真，附件 `type == "queued_command"`，`commandMode == "prompt"`，`(att.get("origin") or {}).get("kind") == "human"`。
   - **取文本**：`prompt` 是 `str` 时直接用；是 list 时只拼接 `type == "text"` 的块，遇到非文本块整条返回 `None`；其他类型返回 `None`。
   - **复用现有检查**：`strip` 后为空返回 `None`，再套用 `NON_HUMAN_MARKERS`。
   - **白名单**：只放行 `human`。`peer` / `task-notification` / `coordinator` / `auto-continuation` 等一律返回 `None`。
4. **时间戳**：`latest_approval` 对附件行同样先取行的 `timestamp`，缺失时取附件内的 `timestamp`。可以抽一个 `row_time(row)` 辅助函数，两处共用。
5. **`verdict()`**：开头先算 `goal = active_goal(rows)`。命中就直接 `return True, "%s · %s" % (iso(when), quote), ""`，不再算新鲜度；未命中，走原有逻辑，原有逻辑一字不改。
6. **文件头注释**：
   - 「判据」段补两行：「人类消息」加上 human 插话附件；新增「持续授权 = 主链最后一条 goal_status met=false，豁免新鲜度，优先于批准词」。
   - 注明形状取自 Claude Code v2.1.319 转录。
7. **不改的东西**：`APPROVE_WORD_RE`、`WORD_LIMIT`、`PLAN_FILES`、hook 的放行规则（`is_takeoff_dispatch` / `find_change_dir` / `locate_hook`）、拒绝文案。`user` 行不新增 `origin` 判定（D5）。
