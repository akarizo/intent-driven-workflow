# S5 · 判定器：每次门禁分层报告耗时（tier_sec）

**做什么**：配置了分层时，`gate` / `baseline` / `final` 输出 `tier_sec`（单元 / 集成 / 各区域秒数），写进 `summary` 与 timeline 备注。语义见 `specs/test-tiers` 的「每次门禁分层报告耗时」Requirement 与 design D14。

**owns**
- `template/.claude/hooks/slice-gate.py`
- `tests/test_tiers_timing.py`

**依赖**
- S1：`_load_tiers(change_dir)` → `(tiers | None, errors)`；`tiers_matching(path, tiers)`（单元层在前、区域按名字排序）。
- S2：baseline / final 里单元层的 `run_test_gate(gate.test, root, probe=True)` + `_unit_tier_verdict(...)` 调用点，区域的 `run_test_gate(rcmd, root)` 调用点与 `bl["regions"][name]["sec"]`。

**做法**
1. 逐条去掉 `tests/test_tiers_timing.py` 的 `XF` 标记，先红后绿（TDD）。护栏 `test_no_tiers_file_no_tier_seconds` 原本不带标记，改完须仍绿。
2. **纯函数** `tier_seconds(durations, tiers)` → `{"unit", "integration", "regions"[, "unclassified"]}`：
   - 文件部分 = nodeid 按 `::` 切的第一段；`tiers_matching` 取第一个；`"unit"` 计入 `unit`，区域名计入 `regions[名]`，空列表计入 `unclassified`；
   - 各项 `round(..., 1)`；`integration = round(sum(regions 的原始值), 1)`；`unclassified` 为 0 时不出现该键；`regions` 只含有耗时的区域。
   - 另加 `_tier_add(ts, unit=0.0, regions=None)` 把墙钟并入已有 `tier_sec`（重算 `integration` 与舍入），`_tier_note(ts)` → `"单元 %.1fs · 集成 %.1fs"`。
3. **G7 耗时**：
   - `G7_PLUGIN` 的 `pytest_runtest_logreport` 开头：`FLIGHT_G7_SEC` 存在时把 `report.duration` 累加到模块级 dict，`report.when == "teardown"` 时写一行 `[nodeid, 秒]` 并丢掉累计；之后原有逻辑一字不改（结果行格式不变）；
   - `_pytest_outcomes(root, targets, gate=None, durations=None)`：`durations` 是 dict 时在临时目录设 `FLIGHT_G7_SEC`，运行后按 nodeid 累加回填；否则不设该变量；
   - `scenario_status(root, data, slice_ids=None, durations=None)` 把 `durations` 透传给 `_pytest_outcomes`；返回形状不变。
4. **gate**（`cmd_gate`）：`_load_tiers` 得到合法 tiers 时 `durations = {}` 传给 `scenario_status`；`result["tier_sec"] = tier_seconds(durations, tiers)`；`summary += "；" + _tier_note(ts)`；timeline 备注 `"%s %s %s" % (slice, _tier_note(ts), "ok"/"red")`。tiers 缺失或不合法 → 什么都不加，备注与现在相同。
5. **baseline**（S2 接好的 `cmd_baseline`）：tiers 合法时
   - `unit` = 全量那段（含 `_unit_tier_verdict`）的墙钟；`regions` = 各区域记录的 `sec`；
   - `bl["tier_sec"]` 写进 `gate-baseline.json` 与 stdout；timeline 备注在结论词前插入 `_tier_note`（如 `exit 0, 0.9s；单元 0.9s · 集成 0.7s ok`）。
6. **final**（S2 接好的 `cmd_final`）：tiers 合法时 `scenario_status(root, data, durations=durations)` → `tier_seconds`；G7 绿时把单元层运行（含 `_unit_tier_verdict`）与各区域运行的墙钟经 `_tier_add` 并入；`result["tier_sec"]`；`summary` 追加；timeline 备注 `"%s %s" % (_tier_note(ts), "ok"/"red")`。G7 红时只报 G7 部分。
7. 文件头注释：gate / baseline / final 的 JSON 契约补 `tier_sec` 一句。

**verify**：`python3 -m pytest -q tests/test_tiers_timing.py tests/test_tiers_gate.py tests/test_tiers_verdict.py tests/test_slice_gate.py tests/test_slice_gate_final.py tests/test_slice_gate_baseline_preflight.py tests/test_evidence_timeline.py tests/test_baseline_incremental.py`

**注意**
- 不改 S1 / S2 的函数签名与判定；不改 `timeline.py`；`preflight` 不加任何东西。
- 无分层文件时：G7 插件不写耗时文件、`gate` / `baseline` / `final` 的输出、`summary`、timeline 备注逐字不变（既有测试全绿即证）。
- timeline 备注的结论词必须仍在末尾，gate 行首词仍是切片号（`timeline.py` 靠它们算切片耗时与红次数）。
- 守护测试做 mutation 自证：把 `tier_seconds` 的归层改成「全部计入 unit」，`test_tier_seconds_split_by_file` 与 `test_slice_gate_reports_tier_seconds` 要变红。
- `compileall` 绿；只用标准库；兼容 Python 3.8。
