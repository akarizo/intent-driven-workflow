# S2 · 判定器：G10 / G11 判定，baseline / final / preflight 按分层运行

**做什么**：在 S1 的分层读取与探针之上，加 G10 / G11 的纯函数判定与候选重跑，把单元层探针、已选区域差分接进 baseline / final / preflight。语义见 `specs/test-tiers` 第四、五条 Requirement 与 design D5–D9。

**owns**
- `template/.claude/hooks/slice-gate.py`
- `tests/test_tiers_verdict.py`
- `tests/test_tiers_gate.py`

**依赖 S1 的接口**（见 `slices/S1.md` 第 2、3、7 步）：`_load_tiers(change_dir)` / `_load_tiers_file(path)` → `(tiers | None, errors)`；`tiers_matching(path, tiers)`；`run_test_gate(cmd, root, probe=True)` → 结果多 `probe`（`{nodeid: {"sec", "hits"}}` 或 None）与 `probe_why`；常量 `UNIT_MAX_SEC`、`TIER_PROBE_PLUGIN`。

**做法**
1. 逐条去掉两个测试文件里的 `XF` 标记，先红后绿（TDD）。护栏 `test_no_tiers_file_gate_unchanged` 原本不带标记，改完须仍绿。
2. **纯函数**（不做 I/O）：
   - `slow_candidates(probe)` → 耗时 `>= UNIT_MAX_SEC` 的 nodeid 列表（排序）；probe 为 None → `[]`；
   - `tier_verdicts(probe, probe_why, rerun, allow)` → `(failed, warnings)`：
     - probe 为 None → `([], ["G10/G11 不可度量：%s" % probe_why])`；
     - 候选里 `rerun.get(nid)` 为 None 或 `>= UNIT_MAX_SEC` 即确认；确认且不在 `allow` → `"G10 slow unit test: %s 首跑 %.1fs，重跑 %s（≥3s）：提速、移入集成区域，或由人类放行（test-tiers.py allow-slow）"`（重跑无记录写「未取得」）；在 `allow` → 警告 `"G10 slow unit test 已人工放行：%s %.1fs（%s）" % (nid, sec, allow[nid]["approved"])`；
     - 有 hits 的用例 → `"G11 impure unit test: %s 碰了%s（%s）：改成纯函数或移入集成区域"`，类别与样例按 hits 的顺序拼。
3. **候选重跑** `_tier_rerun(root, gate, nodeids)` → `{nodeid: sec}` 或 None：前缀用 `_g7_runner(gate)`（`:837`），参数 `-p flight_tier_probe -p no:cacheprovider --rootdir <root> <nodeids…>`；插件写临时目录、env 同 S1；超时用 `_g7_timeout(gate)`（`:848`）；读 jsonl 取各 nodeid 的 `sec`；拿不到输出 → None（调用方按「未取得」处理）。
4. **单元层判定入口** `_unit_tier_verdict(root, gate, tg, allow)`：`cands = slow_candidates(tg["probe"])`；有候选才 `_tier_rerun`；返回 `tier_verdicts(...)`。
5. **差分抽取**：从 `full_suite_verdict`（`:293`）抽出 `_diff_verdict(label, tg, known_failed)`；`full_suite_verdict` 改为调用它，`label="test"` 时输出文本与现在逐字相同；区域用 `label="region <NAME>"`。
6. **baseline**（`cmd_baseline`，`:1407`）：
   - 在 checks 形状校验旁（`:1415-1418`）：`tiers, terrs = _load_tiers(args.change_dir)`；`terrs` 非空，或 `gate.integration` 里有不在 `tiers["regions"]` 的名字 → `die`（不写运行标记）；
   - tiers 存在时候选列表为空（`_baseline_candidates(..., args.full or tiers is not None)`，`:1435`）；
   - 全量那段（`:1455-1465`）tiers 存在时 `run_test_gate(test_cmd, root, probe=True)`，之后 `f10, w10 = _unit_tier_verdict(...)`：`f10` 并入 `reasons`、`w10` 并入 `warnings`；`bl["tiers"] = {"measured": True}` 或 `{"measured": False, "why": tg["probe_why"]}`；
   - verify 之后、`gate.checks`（`:1508`）之前：对 `gate.integration` 每个区域 `run_test_gate(rcmd, root)`，记 `bl["regions"][name] = {"exit", "sec", "cmd"[, "failed"]}`；可度量的红记 `failed` 并警告「区域 NAME 预存红 k 条」；不可度量的红进 `reasons`「区域 NAME 在基线上红（exit N；按退出码判：why）」；
   - tiers 不存在时以上都不发生，`bl` 不出现 `tiers` / `regions` 键。
7. **final**（`cmd_final`，`:1354`）：G7 绿分支里，tiers 存在时单元层用 `run_test_gate(..., probe=True)` + `_diff_verdict("test", …)` + `_unit_tier_verdict`；随后逐个已选区域：基线 `regions.NAME` 缺失或 `cmd` ≠ 分层文件当前 `cmd` → `"G2 region %s：基线缺记录或命令已变，重跑 baseline"`；否则 `_diff_verdict("region " + name, run_test_gate(rcmd, root), rec.get("failed"))`。分层文件存在但不合法 → 一条 `G2 tiers：测试分层文件不合法，先跑 lint 修好`，不跑单元层探针与区域。G7 红时沿用现有警告。
8. **preflight**（`cmd_preflight`，`:1625`）：紧接 `plan_sha` 校验（`:1639`）之后，tiers 存在且有已选区域时逐个核对 `bl["regions"][name]["cmd"]` 与分层文件当前 `cmd`，缺记录或不符 → `die("基线过期：区域 %s 的命令已变或没有基线记录；重跑 baseline" % name)`。
9. 文件头注释：baseline / final / preflight 子命令说明各补一行分层行为；JSON 契约补 `tiers` / `regions` 键。

**verify**：`python3 -m pytest -q tests/test_tiers_verdict.py tests/test_tiers_gate.py tests/test_slice_gate.py tests/test_slice_gate_final.py tests/test_slice_gate_baseline_preflight.py tests/test_baseline_incremental.py tests/test_baseline_pool.py tests/test_baseline_skip.py tests/test_gate_checks_baseline.py tests/test_gate_checks_final.py`

**注意**
- 不改 S1 的函数签名；不改 `lint_plan`；不改 `cmd_gate`。
- 无分层文件时 baseline / final / preflight 的输出、`gate-baseline.json` 字段、复用与入池行为与现在完全相同（既有 baseline / final 测试全绿即证）。
- `UNIT_MAX_SEC` 不读环境变量（design D12）。
- `test_baseline_red_when_unit_test_slow` 会真睡 3.1 秒两次（首跑 + 重跑），属预期；其余慢单测语义由 `tests/test_tiers_verdict.py` 的纯函数测试覆盖。
- 守护测试做 mutation 自证：把确认条件改成「首跑超线即确认」，`test_slow_unit_test_not_confirmed_on_rerun_passes` 要变红；把区域差分改成按退出码，`test_final_diffs_regions_against_baseline` 要变红。
- `compileall` 绿；只用标准库；兼容 Python 3.8。
