# S1 · 判定器：分层文件与 lint、plan_sha、G12、探针

**做什么**：slice-gate 认识仓库级分层文件 `test-tiers.json`：读取与形状校验、lint 的 `tiers:` 规则、`plan_sha` 追加已选区域、切片门禁 G12；再加探针插件与 `run_test_gate(cmd, root, probe=False)`。语义见 `specs/test-tiers` 前三条 Requirement 与 design D1–D4、D9、D13。本片**不**改 baseline / final / preflight 的运行流程（S2 的事）。

**owns**
- `template/.claude/hooks/slice-gate.py`
- `tests/test_tiers_plan.py`
- `tests/test_tiers_probe.py`

**做法**
1. 逐条去掉两个测试文件里的 `XF` 标记，先红后绿（TDD）。两条护栏（`test_lint_accepts_valid_tiers_plan`、`test_no_tiers_file_lint_unchanged`）原本不带标记，改完须仍绿。
2. **常量**（文件头常量区）：`TIER_FILE = "test-tiers.json"`、`UNIT_MAX_SEC = 3.0`、`TIER_NAME_RE = re.compile(r"[a-z0-9-]+")`、`TIER_PROBE_PLUGIN`（插件源，见第 6 步）。
3. **读取与校验**：
   - `_tiers_path(change_dir)` = `os.path.join(<change_dir 上两级>, TIER_FILE)`（与 `_repo_default_checks` 同一解析，`:393`）；
   - `_load_tiers_file(path)` → `(tiers | None, errors)`：文件不存在 → `(None, [])`；读不出 / JSON 不合法 / 顶层非对象 → `(None, ["tiers: 测试分层文件 <path> 无法解析：<原因>"])`；形状问题逐条进 errors（文本以 `tiers:` 开头、点名对象），有错时 tiers 返回 None；
   - 形状规则见 spec 第一条 Requirement：顶层白名单 `unit` / `regions` / `slow_allow`（`unit` 必有）；`unit` 白名单 `paths` / `cmd`；区域名 `TIER_NAME_RE.fullmatch`；区域白名单 `paths` / `covers` / `cmd`（三者都必有，`covers` 可为空数组）；`slow_allow` 每项白名单 `reason` / `approved`，都非空；用 `_nonblank`（`:345`）判非空；
   - `_load_tiers(change_dir)` = `_load_tiers_file(_tiers_path(change_dir))`；
   - `tiers_matching(path, tiers)` → 匹配到的层名列表（`"unit"` 或区域名，按 unit 在前、区域按名字排序），用 `glob_match`（`:308`）。
4. **lint**：`lint_plan(data, change_dir)` 在 `change_dir` 非 None 时追加（放在仓库默认检查之后）：
   - 文件不存在而计划有 `gate.integration` / `gate.integration_skip` → `tiers: 计划写了 gate.integration / integration_skip，但缺少测试分层文件 <path>`；
   - 文件存在：形状错误原样并入；形状合法时再查 `gate.test == unit.cmd`（都 strip）、`integration` / `integration_skip` 的形状与区域名、二者同名、`covers` × 各片 `owns` 用 `globs_intersect`（`:316`）判相交后的表态、`scenario_tests` 的文件部分（`::` 之前）落在 `unit` 或已选区域里；
   - 文本都以 `tiers:` 开头；点名对象（区域名、nodeid、文件路径、`gate.test`）。
5. **plan_sha**（`:247`）：`gate.integration` 是非空 list 时 `key.append(["integration", list(gate["integration"])])`；其余不变。
6. **探针插件** `TIER_PROBE_PLUGIN`（字符串，写进临时目录为 `flight_tier_probe.py`）：
   - `import json, os, sys` 与 `import pytest`；事件集合 FS / PROC / NET 照 spec 第三条 Requirement；跳过模块前缀 `("importlib._bootstrap", "zipimport", "_pytest.assertion.rewrite")`；
   - `sys.addaudithook(_hook)`：窗口外（当前 nodeid 为 None）直接返回；先按事件名集合过滤，命中才 `sys._getframe(1)` 往上看帧的 `f_globals["__name__"]` 是否以跳过前缀开头；类别名用「文件」「子进程」「网络」，每类只留第一条样例 `"<事件名> <args[0] 前 120 字符>"`；
   - `@pytest.hookimpl(hookwrapper=True)` 包 `pytest_runtest_setup` / `pytest_runtest_call` / `pytest_runtest_teardown`：yield 前设当前 nodeid，yield 后清空；
   - `pytest_sessionstart` 写一行 `{"probe": "start"}`；`pytest_runtest_logreport` 累加 `report.duration`，`report.when == "teardown"` 时写一行 `{"nodeid", "sec", "hits"}` 并丢掉该 nodeid 的累计；写文件前先清空当前 nodeid（不记插件自己的 open），写完恢复；
   - 输出路径取 `os.environ["FLIGHT_TIER_OUT"]`，追加写、每行一条 JSON；
   - 兼容 Python 3.8（`sys.addaudithook` 3.8 起有）。
7. **`run_test_gate(cmd, root, probe=False)`**（`:182`）：
   - `probe=False` 时行为与返回完全不变（另加两个键 `probe: None`、`probe_why: None` 可以，但不得改其余键）；
   - `probe=True`：在同一个临时目录写插件文件；env 前置 `PYTHONPATH`、`PYTEST_ADDOPTS` 追加 ` -p flight_tier_probe`、设 `FLIGHT_TIER_OUT`；
   - 输出含 `Error importing plugin "flight_tier_probe"` → 不带探针重跑一次（就是 `probe=False` 的路径），返回它的结果并设 `probe=None`、`probe_why="探针插件加载失败（包装命令覆写了 PYTHONPATH？）；G10/G11 未判"`；
   - 读 jsonl：没有 `{"probe": "start"}` 行 → `probe=None`、`probe_why="没有探针输出（不是 pytest？）"`；否则按 nodeid 合并（`sec` 取最大、`hits` 合并保留先出现的样例）→ `probe={nodeid: {"sec": float, "hits": {...}}}`；
   - 读取发生在临时目录删除之前。
8. **G12**（`cmd_gate`，接在 `gwt_violations` 之后，`:1260`）：`_load_tiers(args.change_dir)` 得到合法 tiers 时，对 `tests` 里 `TEST_FILE_RE.search(f)` 命中且 `os.path.isfile(os.path.join(root, f))` 的文件，`tiers_matching` 结果与 `{"unit"} ∪ set(gate.integration)` 无交集 → `failed.append("G12 tiers: %s 不在单元层或本 change 已选区域的 paths 内（挪到对应目录，或在 gate.integration 选上该区域）" % f)`。分层文件不存在或不合法时不做（不合法由 lint 管）。
9. 文件头注释：lint 子命令说明补一行 `tiers:` 规则；gate 子命令说明里 G1–G8 改成 G1–G8、G12；JSON 契约一节补「探针」一句。

**verify**：`python3 -m pytest -q tests/test_tiers_plan.py tests/test_tiers_probe.py tests/test_slice_gate.py tests/test_gate_checks_lint.py tests/test_slice_gate_baseline_preflight.py tests/test_slice_gate_coverage.py`

**注意**
- 没有分层文件、也没有 `gate.integration` 时，`lint_plan` 返回、`plan_sha`、`run_test_gate(probe=False)`、`cmd_gate` 输出与现在完全相同。
- 守护测试做 mutation 自证：把任一条判定改坏（如去掉 import 帧排除、把相交判断改成恒假），对应断言要变红。
- `compileall` 绿；只用标准库；兼容 Python 3.8。
- 本片新增的 `_load_tiers_file`、`tiers_matching`、`run_test_gate(probe=True)`、`TEST_FILE_RE`、`UNIT_MAX_SEC` 会被 S2、S3 直接调用，名字与返回形状按上面写死。
