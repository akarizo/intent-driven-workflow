# S3 · 脚本：test-tiers.py

**做什么**：新增 `template/.claude/hooks/test-tiers.py`，提供 `/test-tiers` 用的四个子命令 `probe` / `check` / `allow-slow` / `render`。语义见 `specs/test-tiers` 第六条 Requirement 与 design D10、D11。

**owns**
- `template/.claude/hooks/test-tiers.py`
- `tests/test_tiers_cli.py`

**依赖 S1 的接口**（`slices/S1.md` 第 2、3、7 步）：`_load_tiers_file(path)`、`tiers_matching(path, tiers)`、`run_test_gate(cmd, root, probe=True)`、`TEST_FILE_RE`、`UNIT_MAX_SEC`、`toplevel()`、`TIER_FILE`。
**依赖 takeoff-gate**（不改它）：`locate_cli(session_arg)`、`human_text(row)`、`parse_ts(value)`、`summarize(text)`、`iso(dt)`。

**做法**
1. 逐条去掉 `tests/test_tiers_cli.py` 里的 `XF` 标记，先红后绿（TDD）。
2. **导入**：用 `importlib.util.spec_from_file_location` 按本文件同目录的路径加载 `slice-gate.py` 与 `takeoff-gate.py`（文件名含连字符，同 `tests/conftest.py` 的 `load_hook`）。不复制它们的逻辑。
3. **`probe [--cmd CMD] [--json PATH]`**：
   - `root = toplevel()`；`cmd` 缺省 `"%s -m pytest -q" % shlex.quote(sys.executable)`；`tg = run_test_gate(cmd, root, probe=True)`；
   - `tg["probe"]` 为 None → stderr 写 `probe_why`，退出 2；
   - 按文件（nodeid 的 `::` 之前）汇总：纯（无 hits）与不纯用例数、最慢耗时、第一条样例；层级：全纯 = `单元`、全不纯 = `集成`、都有 = `混合`；
   - stdout 每个文件一行，**首列是层级标签**，之后是文件路径、`单元 n · 集成 m`、最慢 `x.xxs`、样例；按文件路径排序；末行 `合计 N：单元 a · 集成 b · ≥3s 的单元候选 c`（候选 = 无 hits 且 `sec >= UNIT_MAX_SEC`）；
   - `--json PATH`：`{"total": N, "tests": {nodeid: {"sec", "hits"}}, "files": {path: {"tier", "unit", "integration", "max_sec"}}}`，`ensure_ascii=False`。
4. **`check [--openspec-root DIR]`**：
   - 分层文件路径 = `<DIR 或 toplevel/openspec>/test-tiers.json`；缺失或 `_load_tiers_file` 报错 → stderr 写明，退出 2；
   - 文件来源 `git ls-files --cached --others --exclude-standard`，取 `TEST_FILE_RE.search` 命中的；
   - `tiers_matching` 结果为空 → 未归层；多于 1 → 匹配多层（列出层名）；有任一 → stdout 逐个点名，退出 1；否则打印「全部 N 个测试文件恰好归一层」，退出 0。
5. **`allow-slow NODEID --reason TEXT [--openspec-root DIR] [--session PATH]`**：
   - 分层文件同上；缺失 / 不合法 → 退出 2；`--reason` 去空白后为空 → 退出 2；
   - `session = locate_cli(args.session)`；找不到 → stderr 说明，退出 3；
   - 逐行读转录，`human_text(row)` 非空且 `parse_ts(row["timestamp"])` 可解析的取**时间最大**的一条；
   - 函数名 = NODEID 最后一个 `::` 之后、去掉 `[` 起的参数化后缀；放行词正则 `放行|允许|allow|approve`（`re.I`）；最新一条同时含二者才成立；
   - 成立 → `slow_allow[NODEID] = {"reason": TEXT, "approved": "%s · %s" % (iso(when), summarize(text))}`，其余键原样保留，`json.dump(..., ensure_ascii=False, indent=2)` + 换行，stdout 打印该条；退出 0；
   - 不成立 → 不写文件，stderr 写「最新一条人类消息（<时间> · <摘要>）里没有同时出现 <函数名> 与放行词；请人类在对话里明确写出放行哪个用例及理由」，退出 3。
6. **`render --probe PATH --plan PATH --out PATH`**：
   - plan = `{"tiers": {...}, "moves": {源: 目标}}`；源是文件路径（整文件搬）或 nodeid（单个用例搬）；nodeid 级 move 优先于它所在文件的 move；
   - 每个探针用例的落点 = 命中的 move 目标，否则原路径；落点所属层 = `tiers_matching(落点, plan["tiers"])`；
   - 问题：落点不属于恰好一层；落点属于 `unit` 而用例有 hits 或 `sec >= UNIT_MAX_SEC`；逐条写 stderr（点名 nodeid）并退出 1；无问题退出 0；HTML 都写出；
   - HTML：单文件、内联 CSS、不引外网资源；页头写问题清单（无则写「无问题」）；表格「源 · 目标 · 所属层 · 耗时 · 触碰样例」；每层的用例数与耗时合计；一个批注 `<textarea>`；按钮「导出 Markdown」（下载含划分摘要与批注的 `.md`）与「复制」；所有插入文本经 `html.escape`。
7. 文件头注释写清四个子命令、退出码约定（0 / 1 / 2 / 3）与「只读不改 slice-gate / takeoff-gate」。

**verify**：`python3 -m pytest -q tests/test_tiers_cli.py tests/test_approval_gate.py`

**注意**
- 只用标准库；兼容 Python 3.8；`compileall` 绿。
- 不改 `slice-gate.py`、`takeoff-gate.py`（S1 / S2 与既有门禁的事）；若发现 S1 的接口不够用，按切片纪律在门禁 JSON 里报 G6 交回规划，不要自己改。
- `allow-slow` 只认**最新**一条人类消息（design D10），不要放宽成「任一条」。
- 守护测试做 mutation 自证：把「最新一条」改成「任一条」，`test_allow_slow_requires_latest_human_message` 的第一段要变红。
