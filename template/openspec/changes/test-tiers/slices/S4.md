# S4 · 文档：/test-tiers 命令与分层规则

**做什么**：新增 `/test-tiers` 命令文档，并把分层规则写进 schema、propose / verify 命令与同名 skill、TDD skill、slice-executor、README、`install.sh` 提示与 `CLAUDE.md.snippet`。语义见 `specs/test-tiers` 最后一条 Requirement 与 design D2、D3、D5–D8、D11、D14。本片只写文档，不改任何 `.py`。

**做法**
1. 去掉 `tests/test_tiers_docs.py` 的 `XF` 标记，先红后绿。
2. **`test-tiers.md`**（frontmatter 带 `description`；命令本身即逻辑，无同名 skill）：按 design D11 写 7 步——`/opsx-mini` 留痕 → `python3 .claude/hooks/test-tiers.py probe --json <f>` → 起草 `{tiers, moves}` 划分稿（区域按模块 / package / library，`covers` 写被测源码 glob，混合文件按 nodeid 拆）→ `test-tiers.py render … --out openspec/superpower/<日期>-test-tiers-plan.html` 并打印绝对路径、**停下等人类批准** → `git mv` / 拆混合文件 / 写 `openspec/test-tiers.json` → `test-tiers.py check` 与再次 `probe` 复核（合计相等、单元层零触碰、无 ≥3 秒单测）并各跑一次 `unit.cmd` 与区域 `cmd` → 提示把进行中 change 的 `gate.test` 改成 `unit.cmd`、`/opsx-mini --done`、不代 commit。另写一节「放行慢单测」：G10 红后由人类在对话里写明「放行 <用例函数名>，理由…」，模型随即跑 `test-tiers.py allow-slow <nodeid> --reason …`；脚本只认最新一条人类消息。另写一节「非 pytest 仓库」：跳过 probe，静态推断并在审批页标「未实测」。另写一节「门禁的分层耗时」：配置了分层时 `gate` / `baseline` / `final` 输出 `tier_sec`（`unit` / `integration` / 各区域秒数），并写进 `summary` 与飞行记录（timeline 备注）；口径见 design D14。
3. **schema.yaml** 的 tasks instruction（`gate.checks` 那段之后）：`gate.integration` / `gate.integration_skip` 的含义；openspec 根有 `test-tiers.json` 时 `gate.test` 必须等于 `unit.cmd`；`covers` 与切片 `owns` 相交的区域必须选上或写理由；写 scenario 骨架前先定层（默认单元层；确需真实文件 / 子进程 / 网络才进集成区域），骨架文件放在该层的 `paths` 里；都由 `slice-gate.py lint` 校验。
4. **opsx-propose.md 与 openspec-propose/SKILL.md**（同改，禁漂移）：step 3 的 tasks 产出里加「写骨架前先定层」一句；step 5 的 baseline 说明里加「配置了分层时 baseline 只跑单元层（带探针判 G10 / G11）与 `gate.integration` 选中的区域，不走增量」。
5. **opsx-verify.md 与 openspec-verify-change/SKILL.md**（同改）：final 的说明里加单元层 G10（慢单测）/ G11（单测不纯）与 `G2 region <NAME>` 区域差分。
6. **test-driven-development/SKILL.md**：新增一节「写测试前先定层」：单元层 = 被测逻辑抽成纯函数，测试不碰真实文件（含 `tmp_path`）、子进程、网络，每个用例连准备与清理 <3 秒；确需真实交互才写集成测试，放进对应区域的 `paths`，并在本 change 的 `gate.integration` 选上该区域；门禁 G10 / G11 / G12 机械校验；仓库没有 `test-tiers.json` 时规则仍建议遵守、门禁不查。
7. **agents/slice-executor.md**：TDD 条目后加一句：新测试先定层，放在单元层或已选区域的 `paths` 里，否则 G12 红。
8. **README.md**：「15 个 slash 命令」→「16 个 slash 命令」（目录树注释与小节标题都改）；命令表加 `/test-tiers` 一行（无同名 skill）；新增一小节「测试分层」：`test-tiers.json` 形状、`gate.integration`、G10–G12、`/test-tiers` 的用途。
9. **install.sh**：安装完成提示里的「15 个 slash command」→「16 个 slash command」，括号里的清单补 `/test-tiers`。
10. **CLAUDE.md.snippet**：TDD 那条附近加一行：「**测试先定层**：单元 = 纯函数且每用例 <3s（基线）；碰真实文件进集成区域（`openspec/test-tiers.json`，G10–G12 机械校验）」。
