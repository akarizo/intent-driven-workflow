# S3 · 审批页：spec.html 渲染选测范围小节

**做什么**：落实 design D8。`spec_html.py` 的飞行计划一节在切片表之后，有有效选测命令或 `gate.scope_full_reason` 时渲染「选测范围」小节。

**owns**
- `template/.claude/hooks/spec_html.py`
- `tests/test_spec_html_scope.py`

**要点**
- 读 `slices.json` 的 `gate.scope`、`gate.scope_full_reason`，以及 `<openspec 根>/gate-scope.json`（openspec 根 = change 目录上两级；读不了或形状不对时当作没有，不抛错——校验归 lint）。
- 有效命令与来源：`gate.scope` → 「计划 gate.scope」；否则默认 `cmd` → 「仓库默认 gate-scope.json」。
- 有 `gate.scope_full_reason` 时渲染「触发项 → 理由」表；所有文本经 `esc()`。
- 只读文件，不运行任何命令；两者都没有时不渲染这一小节（输出与现在相同）。

**依赖切片接口**：无（字段名与文件名以 design D5 / D7 为准）。

**verify**
```bash
python3 -m pytest -q tests/test_spec_html_scope.py tests/test_spec_html.py
```

**scenario**：`gate-scope-report#spec-html-shows-scope-reasons`、`#spec-html-shows-repo-default-scope`。
