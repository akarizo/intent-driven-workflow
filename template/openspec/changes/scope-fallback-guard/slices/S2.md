# S2 · 判定器：lint / preflight 的选测范围契约

**做什么**：落实 design D5–D7、D9。计划 `gate.scope` 或仓库默认 `<openspec 根>/gate-scope.json` 声明选测命令；`lint` 与 `preflight` 实跑它、校验报告、核对 `gate.scope_full_reason` 逐项表态；`waves` 不跑。

**owns**
- `template/.claude/hooks/slice-gate.py`
- `tests/test_gate_scope_lint.py`

**要点**
- 常量：`SCOPE_FILE = "gate-scope.json"`、`SCOPE_TIMEOUT = 300`（不可配置）。仓库默认文件路径与 `_repo_default_checks` / `_tiers_path` 同一解析（change 目录上两级）。
- 形状（有 `change_dir` 即做）：`gate.scope` 有则须非空字符串；`gate.scope_full_reason` 有则须对象、每个值非空字符串；`gate-scope.json` 须是只含非空 `cmd` 的对象（读不了 / 非对象 / 未知字段 / 缺 cmd 都点名）。违规行一律以 `scope:` 开头。
- 有效命令 = `gate.scope` 否则默认 `cmd`；无有效命令却有 `gate.scope_full_reason` → 违规。
- `lint_plan(data, change_dir=None, run_scope=False)`：`run_scope` 为真且有有效命令时实跑——`cwd` = `toplevel()`，`shell=True`，`timeout=SCOPE_TIMEOUT`，环境变量 `GATE_SCOPE_OUT` = 临时目录里的 `scope.json`。失败（非 0 → 含 `exit N` 与输出尾部；超时；缺文件；非 JSON；形状：`full` 须 bool、`triggers` 须字符串数组且 `full` 为真时非空、每项非空、`count` 可选非负 int 且不是 bool、无其它字段）→ 违规并点名字段。
- 表态核对（D7）：`full` 为真 → 键集合须等于 `triggers`（缺：点名触发项并含 `gate.scope_full_reason`；多：点名多出的键）；`full` 为假 → 每个键点名、提示删除。
- 通过时往 stderr 打一行摘要：`scope: 选测范围未全选（N 条）`，或 `scope: 选测范围全选（触发 a、b），已逐项写理由`（无 `count` 时省略条数）。stdout 的 waves JSON 不变。
- 调用方：`cmd_lint` 传 `run_scope=(args.cmd == "lint")`；`cmd_preflight` 传 `True`。`plan_sha` 不动（D9）。

**依赖切片接口**：S1 只改 final / 锚点相关函数，不碰 `lint_plan`；本片在 S1 合回后的 `slice-gate.py` 上继续改（同文件，故串行）。

