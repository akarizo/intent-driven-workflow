**要点**
- **schema**（tasks instruction，`gate.impacted` 段之后）：`gate.scope`（可选，只算范围的命令）、openspec 根 `gate-scope.json`（`{"cmd": ...}`，计划没写时的默认）、契约（git 顶层运行、300 秒、`GATE_SCOPE_OUT` 写 `{full, triggers, count}`）、`gate.scope_full_reason`（全选时逐个触发项写理由，键须等于触发项）、lint / preflight 实跑、失败即红、不进 `plan_sha`。
- **`/opsx-propose` 与 `openspec-propose` skill**（step 3 骨架与 lint 之间）：仓库自带选测（按改动选范围、可能退化为全选）时配 `gate-scope.json` 或 `gate.scope`；lint 报「选测退化为全选」时，先看触发项是不是工作流自己的元数据改动，能修选测就修，不能修再在 `gate.scope_full_reason` 逐项写理由；同时提到 `GATE_SCOPE_OUT`。两份同改。
- **`/opsx-verify` 与 `openspec-verify-change` skill**：「自动全量」一行去掉 `test-tiers.json`，「分层指纹」改称「单元层指纹」，并补一句：分层文件里区域条目与 `slow_allow` 的改动不让 final 全量（区域必跑 / 放行用例所在文件重跑）。两份同改。
- **`/test-tiers`**「放行慢单测」一节：放行后 final 不退回全量，只重跑该用例所在的测试文件。
- **README**：「何时全量」去掉 `test-tiers.json`；`gate.impacted` 附近加一条 `gate.scope` / `gate-scope.json` 说明。
