# S7 · 看得见：审批页与成本归因

## 做什么

两处只读的展示：

1. `spec_html.py`：审批页标出哪些检查是全局守护、wave 测试预算是多少、哪些通配写了理由。规则见 `specs/slice-guards/spec.md` 的 scenario `spec-html-shows-guards-and-wide-owns`，决策见 `design.md` D9。
2. `flight-doctor.py cost`：汇总时间线里的 `wave-check` 事件。规则见 `specs/wave-check/spec.md` 最后一条 Requirement。

## 依赖的接口

`wave-check` 事件的备注格式（S2 定，见 `slices/_interfaces.md`）：

`wave N/M · 守护 <名> Xs[ / <名> Ys] · 测试 Zs（K 个文件）| 测试跳过（<原因>） [· 跨片修复 A 个文件（owns 外 B 个）] · <锁片段> ok|red`

没有守护时没有守护段。动手前先看已合回的 `slice-gate.py` 里 `_wave_note` 的实际写法，以它为准。

## 怎么做

TDD：`tests/test_wave_surfaces.py` 的 2 条骨架现在是红的。

### `template/.claude/hooks/spec_html.py`

只读 `slices.json`，不调 `slice-gate.py`、不跑任何命令：

- **全局守护**：`gate.checks` 里 `slice` 非空的检查，在「测试成本」那一块（现在列检查名的地方附近）加一行或一个小表，标题含「全局守护」并点明「每片门禁与每个 wave 合回后都运行」，列出检查名与 `slice` 命令原文（转义后）。没有这样的检查时不输出这一块。
- **wave 测试预算**：计划写了 `gate.wave_test_budget_sec` 时，在同一处显示「wave 集成检查的测试预算 N 秒」；没写不显示。
- **宽通配理由**：切片带 `owns_wide` 时，在切片表里该片的 owns 单元格下面（或紧邻一列）列出「通配 → 理由」。没有就不加任何东西。
- 所有来自计划的文本都走现有的转义函数。

### `template/.claude/hooks/flight-doctor.py`

- `cost(change_dir)`：扫时间线时多认 `cols[1] == "wave-check"` 的行：
  - `count` 加 1；
  - 守护秒数：备注里「守护 」到下一个 ` · ` 之间的每个 `<数字>s` 相加；
  - 测试秒数：`测试 <数字>s` 取数字相加；备注含「测试跳过」时 `skipped` 加 1、不加秒数；
  - 返回值多一个键 `wave = {"count", "guard_sec", "test_sec", "skipped"}`（秒数保留 1 位小数）；没有 `wave-check` 行时四个值都是 0。
- `cost_text(c)`：`c["wave"]["count"] > 0` 时多打一行，形如 `wave 集成检查 2 次：守护 1.6 秒 · 测试 12.3 秒 · 跳过测试 1 次`（必须含「wave 集成检查 N 次」）；为 0 时不打这一行。
- `wave-check` 行的「测试 Xs」不得被算进 final / baseline 的统计（现有逻辑按事件名筛，确认新事件不会落进去）。
- 文件头注释的 `cost` 说明补一句。

## 注意

- `tests/test_flight_doctor_cost_lock.py` 钉着 `cost` 的现有键：`baseline` / `final` 两个对象的键集合不能变，`wait_sec` 只有 `baseline` 与 `final` 两个键（wave 的排队秒数本片不汇总）。
- `tests/test_spec_html*.py` 钉着审批页现有各块的文字；新内容只在有对应数据时出现，旧计划渲染出的页面必须与今天逐字相同。
- 骨架里的时间线是手写的，第二条 `wave-check` 行没有负载片段，第一条有：解析不要依赖片段个数。
- `spec_html.py` 渲染失败不得抛错中断（现有约定：缺数据就不显示）。
