# S4 · 可见性：flight-doctor.py（forecast / cost / doctor）、spec.html 预告段、install.sh 升级后体检

## 做什么

实现 design D12、D14 中脚本侧的部分。规则原文见 `specs/test-cost-visibility/spec.md`（文档那一条除外）。约束：纯标准库、Python 3.9 兼容、恒 exit 0、只读。

1. **新增 `template/.claude/hooks/flight-doctor.py`**：
   - 用 `importlib.util.spec_from_file_location` 按路径加载同目录的 `slice-gate.py`；只调用 `_interfaces.md`「S4 提供」列出的函数，不复制判定逻辑；
   - 三个子命令与 JSON 形状见 `_interfaces.md`；
   - forecast 的 final 段：
     - 有 `gate.impacted` → `impacted`；
     - 部件形态 → `full`；
     - 否则调 `_pick_anchor` 与 `_full_why`。`_full_why` 给出原因，且基线有 `deps_unmeasured` 时，`why` 写 `依赖图未测（<kind>）：<why>`；
     - 异常 → `unknown`。
   - cost 的归类表放在文件顶部常量（关键词 → 必要 / 可避免），见 design D12；
   - doctor 扫 `<openspec 根>/changes/*/gate-baseline.json`（不含 `archive/`）、锚点池、各 `slices.json` 的 gate 与 `gate-scope.json`。不在 git 仓库里时，锚点一节写「不在 git 仓库，跳过」。
2. **`spec_html.py`**：新增「测试成本预告」段，用子进程调 `flight-doctor.py forecast --change-dir <dir> --json`（超时 30 秒）。失败、超时或非 JSON → 段落写占位「预告不可用：<原因>」（铁律 10）。
3. **`install.sh`**：`--upgrade` 结束时，若目标有 `openspec/` 且有 `python3`，运行 `python3 "$TARGET/.claude/hooks/flight-doctor.py" doctor --openspec-root "$TARGET/openspec" || true`，原样打印。首次安装不跑。
