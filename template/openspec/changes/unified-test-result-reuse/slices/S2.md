# S2 · 判定器 final 侧：gate-scope.json 可选字段、锚点链上限、按 nodeid 差分

## 做什么

只改 `template/.claude/hooks/slice-gate.py`，实现 design D5、D6（final 与取锚点部分）、D11。规则原文：`specs/flight-runner-contract/spec.md`「项目可以声明全局路径、盲区与锚点链上限」，`specs/baseline-anchor-reuse/spec.md`「锚点链上限」（final 场景）与 `anchor-baseline-diffs-final-by-nodes`。约束同 S1。

1. **形状**：`_scope_decl` 的字段白名单加上 `global`、`blind`、`anchor_max_hops`。
   - `global` / `blind` 须是字符串数组；`anchor_max_hops` 须是正整数（bool 不算）；
   - 报错文字见 `_interfaces.md`；
   - 「恰含 cmd 或 builtin 之一」不变。
2. **`_scope_extras(change_dir)`**：返回缺省值或声明值。
3. **global**：
   - `_full_triggers` 新增 `declared_global=()`，Δ 路径用 `fnmatch.fnmatchcase(仓库相对完整路径, glob)` 匹配，触发项为 `declared-global:<glob>`；
   - `_full_why` 输出 `Δ 命中项目声明的全局路径 <glob>：<路径>`；
   - final 与内建提供方的计划期预测都把 `_scope_extras` 的 `global` 传进去（单一出处）。
4. **blind**：`_final_select` 新增 `blind=()`，匹配的现存测试文件并入选中集合；final 的调用方传入。
5. **hops**（D6）：
   - 锚点条目写 `hops`：全量 0，增量 final 写来源 + 1；
   - `_anchor_hops(entry, max_hops)` 推断旧条目；
   - `_pick_anchor` 新增 `max_hops`，滤掉 `hops >= max_hops` 的锚点；因此没有可用锚点时，原因写 `锚点链已达上限 <K> 代（anchor_max_hops）`，触发项 `final:anchor-hops`；
   - `ANCHOR_MAX_HOPS = 5`。
6. **按 nodeid 差分**（D11）：基线 `test.failed_form == "nodes"` 时，final 全量用依赖图逐用例结局与 `test.failed_nodes` 差分；拿不到逐用例结局 → G2 test 红，原因见 design D11。
