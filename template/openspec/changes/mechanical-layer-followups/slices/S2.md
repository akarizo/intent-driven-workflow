## 怎么做

1. **clean-after-merged.md 运行方式一节**（design D1、D2）
   - 「`cd` 不跨调用保留」条：把「起始 CWD 就是主会话所在目录」改为「起始 CWD 是主会话当前所在目录：主会话 `cd` 过也一样（2026-11-20 探针实测：主会话 `cd` 进子目录后，普通子 agent 与 fork 子 agent 的首条 `pwd` 都是该子目录）」；`--protect` 处写明「传绝对路径，即 step 1 `pwd` 的输出」。
   - 「最后一条回复」条改为：**最后一条回复就是交给用户的全部汇报**，依次包含 step 2 的计划原文、step 4 的 `done` / `failed` 与 manual 档代码块、step 5 的验证输出；主会话不再复述。
2. **step 2**：「输出（safe / manual / keep 三段）原样展示，不改写、不删减。」改为「输出（safe / manual / keep 三段）原样放进最后一条回复，不改写、不删减。」
3. **step 5**：命令块之后加一行「两条命令的输出原样放进最后一条回复。」
4. **原因表 `session-cwd` 一行**：说明改为「主会话 CWD 在此 worktree 内；只保护 `--protect` 传入的路径。主会话先回主仓库根再删」。
5. **merged-cleanup.py 头注释**：`--protect P` 那行补「P 应为绝对路径（相对路径按本脚本的 CWD，即主 worktree 根解析）」。
6. **tests/test_fork_commands_docs.py**：docstring 改成「fork-mechanical-commands 与 cleanup-fork-report 的 scenario 测试（已解锁）。」，去掉 import 区多余的空行（第 4–5 行）。
