# S7 · 审批页显示轮次档

## 做什么

`template/.claude/hooks/spec_html.py` 渲染的切片表多一列「轮次档」，让批准计划的人看到每片是标准档还是大片档。规则原文见 `specs/turn-tiers/spec.md` 的 `spec-html-shows-turn-tier`，决策见 `design.md` D3、D4。

## 依赖的接口

见 `slices/_interfaces.md` 的 S3 节：

- `python3 <hooks 目录>/slice-gate.py turns --change-dir <change 目录>` → stdout 一个 JSON 对象 `{"S1": "standard", "S2": "large"}`，退出 0；计划不合法退出 2；不在 git 仓库里会失败。

本文件已有：`render_flight(change_dir)`（切片表在这里拼，表头是 `切片 / 标题 / wave / deps / owns / verify`）、`render_forecast(change_dir)`（已有一处「用子进程调同目录另一个 hook、带超时、失败留占位」的写法，照它来）、`esc()`。

## 怎么做

TDD：`tests/test_spec_html_turns.py` 的 1 条骨架现在是红的。

1. `slice_turns(change_dir)` → `{id: 档位}` 或 `{}`：用 `sys.executable` 调同目录的 `slice-gate.py turns --change-dir <change_dir>`，`cwd` 设为 change 目录，超时沿用 `FORECAST_TIMEOUT`；非 0 退出、超时、输出不是 JSON 对象 → `{}`。
2. `render_flight`：表头在 `verify` 之后加 `<th>轮次档</th>`；每行末尾加一格：`large` → `大片档`，`standard` → `标准档`，取不到 → `—`。
3. 文件头注释若列举了切片表的列，同步。

## 注意

- 审批页是「脚本渲染失败不阻塞」的（铁律 10）：`turns` 调不通时这一列全是「—」，页面照常生成、退出码仍为 0。
- 行的拼法是 `'<tr><td class="mono">%s</td>…'`，骨架按 `<tr>` 切行、按 `class="mono">S1<` 找行，别改这一格的写法。
- `tests/test_spec_html.py` / `test_spec_html_scope.py` / `test_spec_html_glossary.py` 多数在 `tmp_path`（不是 git 仓库）下渲染，走的就是「取不到」分支，必须保持绿。
- 不要在 `spec_html.py` 里重算档位（规则只在 `slice-gate.py` 一处）。

## 解锁

去掉 `tests/test_spec_html_turns.py` 那个用例的 `@PENDING`，连同 `PENDING` 定义与 `import pytest` 一起删除。MUST NOT 改断言与函数名。
