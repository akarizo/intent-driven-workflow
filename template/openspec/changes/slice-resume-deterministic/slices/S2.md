# S2 · 留痕 hook 写共用目录

## 做什么

改 `template/.claude/hooks/test-evidence.py`：工作树根有切片标记时，把留痕写到 `<git common dir>/flight-evidence/<change>/<切片>.log`，任何 Bash 事件都留心跳，并认本片 `verify` / `gate.test` 里的脚本路径。规则原文见 `specs/slice-evidence-shared/spec.md` 的第一条 Requirement，决策见 `design.md` D6 的「位置」与「hook」两点，来由见 design「调查一」。

本片只改 hook。门禁读共用目录、`record` 并回分支在 S5。

## 现状（改之前先读）

- `find_change(root)` 三级找 change 目录：切片标记 → 分支名 → 唯一候选；返回 `(change_dir, slice_id)`，没有标记时 `slice_id` 是 `-`。
- `main()`：不是 Bash 或没命中 `TEST_RE` 就返回；否则往 `<change_dir>/evidence.log` 追加一行。
- 整个脚本 fail-open：`__main__` 里吞掉一切异常，恒 `sys.exit(0)`。

## 怎么做

TDD：`tests/test_evidence_shared_hook.py` 的 3 条骨架现在是红的。

1. 区分两种来源：`find_change` 多返回一个「是否来自切片标记」（或拆出 `read_marker(root)`）。**只有来自标记时**走共用目录；其余两级照旧写工作树里的 `evidence.log`。
2. 共用目录路径：`git -C <root> rev-parse --git-common-dir`（相对路径按 root 解析），拼 `flight-evidence/<os.path.basename(change_dir)>/<slice>.log`。取不到共用目录 → 当作没有标记处理（写工作树）。
3. 有标记时的顺序：先 `os.makedirs(..., exist_ok=True)` 并以追加方式打开一次（确保文件存在，即心跳），**这一步在判断是不是测试命令之前**；再判断命令是否算测试运行，是则追加一行（格式不变）。
4. 认定测试运行：`TEST_RE.search(cmd)`，或命令文本包含任一「脚本路径记号」。记号来自 `<change_dir>/slices.json`：取本片的 `verify` 与顶层 `gate.test`，用 `re.split(r"[\s;&|()'\"]+", …)` 切开，保留含 `/` 且以 `.sh` / `.py` / `.js` / `.mjs` / `.ts` 结尾的。读不到或解析失败 → 记号为空（只按运行器名字认）。
5. 文件头注释更新：留痕的两个去处、心跳、认定规则。

## 注意

- 心跳只在有标记时留；没有标记的会话不要在共用目录里建任何东西。
- `tests/test_evidence_timeline.py` 里 `test_evidence_log_records_test_runs`、`test_evidence_log_records_failed_run`、`test_evidence_ignores_non_test_commands` 三条是在**有标记**的仓库里断言工作树的 `evidence.log`，实现后会红。它在本片 owns 内：把这三条改成断言共用目录里的文件（第三条改为「共用目录文件存在但没有行、工作树里没有 `evidence.log`」），GWT 注释同步。同文件的 `test_evidence_resolves_change_from_branch`、`test_evidence_skips_ambiguous_change`、`test_evidence_single_candidate_fallback`（无标记路径）一个字都不用改，必须保持绿；stop-gate / timeline / session-decompose 的用例不碰。
- 命令列仍截 120 字符；`PostToolUseFailure` 恒记 FAIL。
- 行是一次 `write` 追加一整行，不加锁（并行切片写的是各自的文件）。
- 不新增依赖，兼容 Python 3.8+。

## 解锁

去掉 `tests/test_evidence_shared_hook.py` 三个用例的 `@PENDING`，`PENDING` 不再使用时连同定义与 `import pytest` 一起删除。MUST NOT 改这三条的断言与函数名。
