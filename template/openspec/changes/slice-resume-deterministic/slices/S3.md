# S3 · 轮次分档：turns 子命令与 lint 校验

## 做什么

给 `template/.claude/hooks/slice-gate.py` 加子命令 `turns`（打印每片的档位）与 lint 对计划字段 `turns` 的校验。规则原文见 `specs/turn-tiers/spec.md` 的前两条 Requirement，决策见 `design.md` D3，阈值的依据见 design「调查二」。

## 依赖的接口

见 `slices/_interfaces.md` 的 S1 节（S1 改的是 `cmd_start`，与本片不相交；列为依赖只因同改一个文件）。本文件已有：

- `load_plan(change_dir)`、`lint_plan(data, change_dir=None, run_scope=False, phase="lint")` → `(errors, waves)`、`cmd_lint(args, print_waves=True)`、`die(msg)`（退出 2）。
- `load_baseline(change_dir)` → dict 或 `None`，顶层有 `commit`。
- `glob_match(path, pattern)`、`_gitlinks(root)`（索引里的 gitlink）、`_sub_git(root, p, *args)`、`_sub_ready(root, p)`、`toplevel()`。

## 怎么做

TDD：`tests/test_turn_tiers.py` 的 3 条骨架现在是红的（`turns` 子命令不存在）。

1. 常量（放在 `MAX_OWNS` 附近）：`TURN_LARGE_FILES = 8`、`TURN_TIERS = ("standard", "large")`。
2. `_turn_tree(root, change_dir)` → 用来数文件的那棵树的 commit：基线有 `commit` 且 `git cat-file -e <commit>^{commit}` 成功 → 它；否则 `"HEAD"`。
3. `_owned_file_count(root, commit, owns)`：`git ls-tree -r -z <commit>` 逐条取 `(mode, sha, path)`；普通条目用 `glob_match(path, o)` 对 owns 任一条命中即计 1；mode 为 `160000` 的条目（gitlink，路径 P）：owns 里有以 `P/` 开头的条目且 `_sub_ready(root, P)` 时，在子仓里 `git ls-tree -r --name-only <sha>`，对去掉 `P/` 前缀后的 owns 计数；子仓取不到按 0。
4. `slice_turns(data, change_dir, root)` → `{id: 档位}`：规模档 = `"large" if 文件数 > TURN_LARGE_FILES else "standard"`；切片写了 `"turns": "large"` → `large`；其余按规模。
5. lint（`lint_plan` 的切片循环里，紧跟 owns 条数检查）：`turns` 字段存在而不在 `TURN_TIERS` 里 → `errors.append("turns: %s 的 turns 须是 standard / large" % id)`。「降档」检查需要 git：只在 `change_dir is not None` 时做——算出规模档是 `large` 而计划写了 `standard` → `"turns: %s 展开后现存 %d 个文件（> %d），按规模是大片档，不能写 standard（删掉该字段或写 large）"`。取不到 git 顶层（不在仓库里）时跳过降档检查，不报错。
6. `cmd_turns(args)`：`load_plan` → `lint_plan(data, args.change_dir, run_scope=False)`，有错照 `cmd_lint` 的方式 `die`；否则 `print(json.dumps(slice_turns(...), ensure_ascii=False))`。argparse 加 `turns` 子命令（`--change-dir` 必填），分发表加一项，文件头注释加一行。

## 注意

- `lint` / `waves` / `preflight` 的 stdout 仍然只是 waves 数组，不要往里加档位。
- 不写任何文件（`DRAFT-measurements-stay-out-of-plan-files`）。
- `tests/test_slice_gate.py` 的 lint 用例有的 `change_dir` 在 `tmp_path` 下、不在 git 仓库里：第 5 步的「取不到 git 顶层就跳过」就是为它们留的，这些用例必须保持绿。
- `lint_plan` 末尾的选测相关调用（`_lint_scope` 等）是在飞的 `ship-rerun-hardening` 在改的区域，本片只在切片循环里加两句，别动那一段。
- 只数已提交的文件：用 `git ls-tree`，不要用 `os.walk` / `git ls-files`（后者含未提交的暂存）。
