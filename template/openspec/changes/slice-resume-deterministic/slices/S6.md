## 依赖的接口

见 `slices/_interfaces.md` 的 S3、S4 节：

- `python3 .claude/hooks/slice-gate.py turns --change-dir openspec/changes/<name>` → stdout 一个 JSON 对象 `{"S1": "standard", "S2": "large", …}`，退出 0；计划不合法退出 2。
- 工作流参数 `turns`（可选）：上面的输出原样传入；值为 `large` 的片派 `slice-executor-large`（80 轮），其余派 `slice-executor`（40 轮）。
- 重派：`slice-gate.py start <S> --continue <上一轮 commit> --expect-branch <branch>`，不再有「第零步」，不再传 `--base`。
- 未交回的 blocked 理由：`执行体未返回（已重派一次）：<档位>上限 <N> 轮；半成品快照在 refs/flight/<change>/<S>，重新起飞的首轮会清掉它，要保留先在新 worktree 里 start <S> --resume-checkpoint`。
- 留痕：切片的留痕在 `<git common dir>/flight-evidence/<change>/<S>.log`，`record` 时并进分支上的 `evidence.log`；`merge` 合回后回收临时 worktree（输出的 `reaped` 与「未回收」警告）。
