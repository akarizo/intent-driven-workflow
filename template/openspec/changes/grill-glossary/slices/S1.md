# S1 · spec_html.py 列出工件里的避用词（只提示）

## 做什么

`spec_html.py` 渲染时读项目的 `openspec/glossary.md`，扫本 change 的 `proposal.md`、`design.md`、`specs/**/*.md`，有避用词命中就在面板里多出「术语对照（只提示）」一节；没有术语表或没有命中时什么都不出现。规则原文见 `specs/domain-glossary/spec.md` 第三条 Requirement，决策见 `design.md` D2、D4、D5。

只提示：不改退出码，不碰 `flight` 块和其他块的输出。

## 依赖的接口

无（与 S2 并行）。两片共用的只有术语表格式（design D2），本片按它解析，S2 把它写进 `grill-me`。

## 怎么做

TDD：先确认 `tests/test_spec_html_glossary.py` 的 3 条骨架是红的（strict xfail），再写实现。

1. **解析术语表**（design D2），新增纯函数，例如 `parse_glossary(text) -> [(规范词, [避用词…])]`：
   - 词条行 `^\*\*([^*]+)\*\*\s*[：:]\s*\S`；
   - 避用行 `^避用\s*[：:]\s*(.+)$`，归属最近的上一个词条；别名按 `、` `，` `,` `/` 拆开、去空白、丢空串；
   - 第一个词条之前的避用行、其他所有行都忽略。
2. **逐行找命中**（design D4），新增纯函数，例如 `glossary_hits(change_dir, entries) -> [(相对路径, 行号, 避用词, 规范词)]`：
   - 文件：`proposal.md`、`design.md`、`specs/**/*.md`，按相对路径排序；路径用 `/`、相对 change 目录（如 `specs/x/spec.md`）。
   - 围栏代码块（以 ```` ``` ```` 开头的行之间）整段跳过；行内代码 `` `…` `` 先换成等长空白。
   - 候选词 = 全部规范词 + 全部避用词，按长度从长到短；依次找每个候选词在这一行的**所有**出现，跳过与已占位置重叠的；规范词占位不报，避用词占位记一条命中。
   - 只含 ASCII 的词：整词（前后不是 `[A-Za-z0-9_]`）、不分大小写；其余按子串。
   - 同一行同一个避用词只记一条；显示的避用词取术语表原文（不取正文里的大小写）。
   - 结果按 文件 → 行号 → 首次出现位置 排序。
3. **渲染**（design D5）：
   - `BLOCK_NAMES` 加 `"glossary"`；`render()` 里 `blocks["glossary"] = render_glossary(change_dir)`。
   - 术语表路径：`os.path.join(project_root(change_dir), "openspec", "glossary.md")`（与 `scan_adrs` 同法）。
   - 有命中时返回一整节：
     ```html
     <section id="glossary"><h2><span class="eyebrow">Glossary</span>术语对照（只提示）</h2>
     <p>…一句说明：工件里用了术语表 openspec/glossary.md 的避用词，批准前可改成规范词…</p>
     <table class="flight-table"><thead><tr><th>位置</th><th>避用词</th><th>规范词</th></tr></thead>
     <tbody><tr><td><code>proposal.md:3</code></td><td>上线</td><td>起飞</td></tr>…</tbody></table></section>
     ```
     每个单元格的值都过 `esc()`。
   - 没有术语表、解析不出词条、没有命中、读或解析时抛任何异常 → 返回 `None`。
   - 不计入 footer 的 `section_count`（那串 key 列表不加 `glossary`）。
4. **模板** `template/.claude/skills/spec-html-render/templates/spec.html.tmpl`：在 `<section id="capabilities">…</section>` 与 `<section id="specs">` 之间插入两行空占位：
   ```html
       <!-- block:glossary -->
       <!-- /block:glossary -->
   ```
   ⚠ 占位之间不放任何文字（测试断言两者之间只有空白），模板任何地方不出现「术语对照」；侧栏导航不加链接。
5. **`template/.claude/skills/spec-html-render/SKILL.md`**：第 36 行附近的 block 清单在 `capabilities` 与 `specs` 之间补一项：`glossary`（读 `openspec/glossary.md`，列出 proposal / design / specs 里的避用词命中；没有术语表或没有命中时保留空占位，页面不显示）。其余原文不动。
