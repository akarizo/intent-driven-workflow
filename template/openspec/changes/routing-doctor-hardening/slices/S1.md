## 怎么做

- **`model-routing.py` `cmd_frontmatter`**（design D1）：
  - `read_bytes()` 包 `try/except OSError` → `die(EXIT_INVALID, ["%s：读不了命令文件 %s：%s" % (name, path, e)])`；
  - `.decode("utf-8")` 包 `except UnicodeDecodeError` → `die(EXIT_INVALID, ["%s：%s 不是 UTF-8 文本" % (name, path)])`；
  - `write_bytes()` 包 `except OSError` → `die(EXIT_INVALID, ["%s：写不了命令文件 %s：%s" % (name, path, e)])`；
  - 文件头退出码说明的 exit 2 行补「命令文件读不了 / 不是 UTF-8 / 写不了」。
- **`flight-doctor.py` `doctor_routing`**（design D2）：
  - `subprocess.run` 去掉 `text=True`，改为 `encoding="utf-8", errors="replace"`；
  - `returncode == 1` 且 `lines` 为空 → `["[routing]", "  不可用：%s" % (stderr 最后一个非空行 或 "exit 1")]`，不追加修法行；
  - 其余分支不变。
- **现有两个 doctor 用例改隔离**（design D3，非 scenario 骨架，本片顺手改）：
  - `test_doctor_reports_frontmatter_drift` 与 `test_doctor_reports_frontmatter_in_sync` 改用补断言时新增的复制 hooks helper（`isolated_hooks` / `run_isolated_doctor`），命令文件按 `FORK_LINES`（sonnet · low）写进 `tmp/.claude/commands/clean-after-merged.md`；
  - drift：`tmp/openspec/model-routing.json` 写 haiku · medium，断言与原来相同，"内容不变"改为断言临时命令文件字节不变；
  - in-sync：命令文件的 model / effort 取复制出来的 `model-routing.py get cleanup.runner --openspec <tmp/openspec>`（无配置）的输出，再写命令文件；
  - 删掉不再使用的 `REAL_CMD` 与 `doctor()` helper（自己造的 orphan 自己清）。
