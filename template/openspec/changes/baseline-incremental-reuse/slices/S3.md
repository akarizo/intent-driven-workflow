# S3 · 判定器：lint / typecheck 沿用、verify 从全量 junit 推导

**做什么**：两件事，语义见 `specs/baseline-redundant-run-skip` 与 design D10、D11。原仓没有这两项，是本仓新增。
- 本 change 的严格差异为空、且命令与指纹不变时，lint / typecheck 沿用上次结论；
- 全量可度量时，可推导的 verify 按全量 junit 判，不单独运行。

**owns**
- `template/.claude/hooks/slice-gate.py`
- `tests/test_baseline_skip.py`
- `tests/test_slice_gate.py`（只为第 5 步的断言放宽；首次起飞漏划，2026-10-15 补入）

**做法**
1. 逐条去掉 `tests/test_baseline_skip.py` 里 4 条 S3 xfail 标记，先红后绿（TDD）。3 条护栏原本就不带标记，改完须仍绿。
2. **`run_test_gate` 交出用例集**：
   - 结果新增 `cases`：rc 0 与可度量的 rc 1 时，解析 junit，取全部 `testcase` 的 classname 集合；解析失败、junit 不存在或不可度量时为 `None`。
   - rc 0 时也读 junit，但不改变 rc 0 的其余判定（`failed` 仍为 None、`why` 仍为 None）。
   - 既有字段与语义不变；`full_suite_verdict` 等调用方忽略 `cases`。
3. **verify 推导**（D11）：新增 `_pytest_head(cmd)`，返回 `(prefix_tokens, rest_tokens)` 或 None。
   - **前缀认法**：同 `_g7_runner` 从 `gate.test` 推导的那段规则：找 `pytest` / `py.test` 词，或 `-m pytest`；之前不能有 `&&`、`||`、`;`、`|`、`cd`、`VAR=` 赋值。
   - **不读 `gate.pytest`**；`_g7_runner` 本身的行为不改。
   - **白名单**：`WHITELIST = {"-q", "-qq", "-v", "-vv", "-x", "-s", "--no-header"}`，加上以 `--tb=` 开头的词，以及成对的 `-p` `no:cacheprovider`。
   - **全量可推导**：`gate.test` 的 rest 只含白名单与路径（路径 = 不以 `-` 开头的词）。
   - **某片可推导**：verify 的 prefix 与全量的逐词相同；rest 只含白名单与路径；至少一个路径；每个路径都不含 `::`，是 `os.path.isfile(root/路径)`，文件名匹配 `test_*.py` 或 `*_test.py`。
   - **模块判定**：`m = 路径[:-3].replace("/", ".")`。`cases` 里有 `== m` 或以 `m + "."` 开头的；`failed` 里没有 classname 部分（`::` 之前）`== m` 或以 `m + "."` 开头的。
   - **结果与范围**：满足 → `bl["verify"][S] = {"exit": 0, "cmd": vcmd, "derived": "full"}`，不运行；否则照旧运行。只在本次跑了全量（`hit is None`）时推导。
   - **timeline**：全量行有推导片时追加 `；verify 推导 k 片`。
4. **lint / typecheck 沿用**（D10）：
   - `bl[kind]` 记 `{exit, lines, cmd, key}`，`key = cmd_key(root, change_rel, cmd)`；
   - `_delta` 加关键字参数 `strict=False`；`strict=True` 时不排除 `<changes 根>` 下其他 change 的路径，其余排除规则不变；
   - 沿用条件：`hit is not None`、`src is own`、`_delta(..., same_change=True, strict=True) == []`、旧记录 `cmd` 与 `key` 都等于当前；
   - 满足 → `{exit, lines, cmd, key, "reused": True}`，取旧记录的 `exit`、`lines`，不运行；
   - `--full` 时没有候选，自然照跑。
5. **既有断言放宽**：`tests/test_slice_gate.py::test_baseline_records_empty_lines_for_green_lint` 的 `assert bl["lint"] == {"exit": 0, "lines": []}` 改为只比 `exit` 与 `lines`（`bl["lint"]["exit"] == 0` 且 `bl["lint"]["lines"] == []`），Then 注释同步。原语义「成功输出不记进基线行」不变；该文件其余用例不动。
6. **两条 lint 重跑用例**：S1 合回后 lint 每次都重跑，`test_lint_rerun_when_other_change_edited`、`test_lint_rerun_when_referenced_plan_file_changed` 已经 XPASS(strict)。去掉它们的标记即可；不改 Then 断言。
