# S3 · 判定器：checks 注入 Δ、gate.impacted、增量与分层叠加

**做什么**：
- final 运行 checks 时注入 `GATE_FINAL_MODE` / `GATE_DELTA_FILE` / `GATE_ANCHOR_COMMIT`；
- 支持 `gate.impacted`（运行与 lint）；
- 有分层时增量只重跑选中的单元层文件并挂探针，区域按需运行。

语义见 `specs/incremental-final` 的后三条判定器 Requirement 与 design D7–D9。

**owns**
- `template/.claude/hooks/slice-gate.py`
- `tests/test_final_checks_env.py`
- `tests/test_final_impacted.py`
- `tests/test_final_tiers.py`

**依赖（S1 / S2 提供的接口）**
- S1：`run_test_gate(..., deps=True)`、`_pytest_outcomes(..., deps_out=...)`、锚点池。
- S2：
  - `cmd_final` 的三条路径；
  - 增量路径里的 Δ 列表、锚点 `{"change", "commit"}`、选中文件 `files`；
  - `_full_why(...)`；`incremental` 段；
  - final 记录（`flight-final/<change>.json`）与 `_final_fps`。

**做法**
1. **TDD**：逐条去掉三份测试文件的 `XF` 标记，先红后绿。
2. **checks 注入**（design D7）：
   - `_check_env(phase, change, base_commit, cdir, final_ctx=None)`；
   - `_final_checks(root, change_dir, checks, baseline, final_ctx=None)` 把 `final_ctx` 透传；
   - `final_ctx = {"mode": "incremental"|"full", "delta": [...] | None, "anchor": commit | ""}`；Δ 写进 `<cdir>/.gate-delta.txt`，每行一个；没有 Δ 时 `GATE_DELTA_FILE` 为空串；
   - baseline 调用不传，行为不变。
3. **`gate.impacted`**（design D8）：
   - **lint**：存在且不是非空字符串时，报 `gate.impacted 必须是非空字符串`；
   - **plan_sha**：确认 `plan_sha` 覆盖它，未覆盖就补上，同时保证没有它的计划的 `plan_sha` 不变；
   - **增量路径**：存在时不做内建选测，改为 `run_test_gate(gate.impacted, root)`，env 加 D7 的三个变量（`_check_env` 同源函数），按基线 `test.failed` 用 `_diff_verdict` 判红；
   - **锚点**：本 change 最近一次绿的 final 记录的 commit，它不是 HEAD 的祖先时取 `gate-baseline.json` 的 commit 与快照；
   - 全局文件与 `--full` 照旧触发全量；
   - `incremental.source = "impacted"`。
   - `run_test_gate` 需要能接收额外 env：加可选参数 `extra_env=None`，默认行为不变。
4. **分层叠加**（design D9）：
   - **单元层**：选中文件 ∩ `unit.paths` 用 `_pytest_outcomes(..., deps_out=..., probe_out=...)` 重跑。`probe_out` 是新增可选参数，加载 `TIER_PROBE_PLUGIN`，产出与 `run_test_gate` 相同形状的 probe。对 probe 走 `slow_candidates` / `_tier_rerun` / `tier_verdicts` 同一套判定，得到 G10 / G11；
   - **区域**：已选区域只在选中文件落在其 `paths` 时运行，沿用 S2 前的区域运行与差分代码，否则进 `incremental.regions_skipped`；
   - **`tier_sec`**：只计实际运行的部分，复用 `tier_seconds` / `_tier_add`。

**verify**：`python3 -m pytest -q tests/test_final_checks_env.py tests/test_final_impacted.py tests/test_final_tiers.py tests/test_final_incremental.py tests/test_gate_checks_final.py tests/test_gate_checks_lint.py tests/test_tiers_gate.py tests/test_tiers_plan.py tests/test_tiers_timing.py`

**注意**
- 没有 `gate.checks` / `gate.impacted` / 分层文件的仓库，行为与 S2 完成后逐字相同。
- 既有 checks 测试（`test_gate_checks_final.py` 等）断言的环境变量与日志行为不变，新变量只做加法。
- 守护测试做 mutation 自证：
  - 把区域「按需」改成「恒运行」，`test_tiers_region_runs_only_when_selected` 要变红；
  - 不写 Δ 文件，`test_final_checks_receive_delta_and_anchor` 要变红。
- 只用标准库，兼容 Python 3.8；`compileall` 绿。
