# S1 · 判定器：嵌套会话防护、依赖图记录、baseline 写锚点

**做什么**：
- 库注入的 pytest 运行带上防护插件，嵌套会话不写 junit、不写探针 / 依赖图记录；
- 新增依赖图插件与 `sitecustomize`；`run_test_gate` 与 `_pytest_outcomes` 可选记录依赖图；
- baseline 跑全量时写锚点池，并在 `gate-baseline.json` 记 `failed_nodes`。

语义见 `specs/incremental-final` 的前两条 Requirement 与 design D1–D3。

**owns**
- `template/.claude/hooks/slice-gate.py`
- `tests/final_helpers.py`（共用被测仓库；S2 / S3 只读使用，本片可按需修正但不改既有函数签名）
- `tests/test_final_guard.py`
- `tests/test_final_deps.py`

**依赖**：无（叠在 test-tiers 之上：`TIER_PROBE_PLUGIN`、`TIER_PLUGIN_FAIL`、`run_test_gate(cmd, root, probe=False)`、`_read_probe`、`G7_PLUGIN`、`_pytest_outcomes(root, targets, gate=None, durations=None)`、`_pool_write` / `_pool_read` / `_pool_order`、`_snapshot`、`cmd_key`、`cmd_baseline` 已存在）。

**做法**
1. **TDD**：逐条去掉 `tests/test_final_guard.py`、`tests/test_final_deps.py` 的 `XF` 标记，先红后绿。
2. **防护插件 `GUARD_PLUGIN`**：常量文本，写进临时目录为 `flight_guard.py`。
   - `pytest_configure`（`tryfirst=True`）按 design D1 判外层 / 嵌套：
     - 外层：设 `os.environ["FLIGHT_GUARD_OWNER"]`；
     - 嵌套：`config.option.xmlpath = None`，并设 `os.environ["FLIGHT_GUARD_NESTED"] = "1"`。
   - `pytest_configure_node(node)` 用 `@pytest.hookimpl(optionalhook=True)`，给外层的 worker 写 `node.workerinput["flight_outer"] = 1`。
   - 探针插件（`TIER_PROBE_PLUGIN`）与依赖图插件在写任何记录前检查 `FLIGHT_GUARD_NESTED`，为真就不写。
3. **依赖图插件 `DEPS_PLUGIN` 与 `SITECUSTOMIZE`**（写进同一临时目录为 `flight_deps.py`、`sitecustomize.py`），按 design D2：
   - 测试文件键 = `item.path`（无则 `item.fspath`）对 `FLIGHT_ROOT` 的相对路径，`/` 分隔；
   - 审计钩子在收集窗口（`pytest_pycollect_makemodule` hookwrapper，键为该模块文件）与用例窗口里记 `open`：
     - `__pycache__/<stem>.<tag>.pyc` 映射回 `<dir>/<stem>.py`；
     - 只收 realpath 落在仓库根之内、不在 `.git/` 与门禁临时目录内的文件；
   - `subprocess.Popen` / `os.exec` / `os.posix_spawn` 事件：argv 里落在仓库内的路径记为依赖；Python 解释器而 `env` 显式给出且 `PYTHONPATH` 不含临时目录、或 argv 含 `-I` / `-S` / `-E` 时，当前测试文件记为盲；
   - 每个用例窗口开始时设 `os.environ["FLIGHT_DEPS_FILE"]` 为当前测试文件键；
   - `pytest_runtest_logreport` 记 `[仓库相对 nodeid, outcome]`，口径同 `G7_PLUGIN`；仓库相对 nodeid = 测试文件键 + `::` + nodeid 里 `::` 之后的部分；
   - 会话结束：对每个测试文件解析 AST 取全部 import，按搜索根（rootdir、测试文件目录链、`sys.path` 里在仓库内的项）解析到仓库内 `.py` 并求传递闭包，并入依赖；
   - 所有记录以 JSON 行追加进 `FLIGHT_DEPS_OUT`（xdist worker 各自追加）；
   - `SITECUSTOMIZE`：`FLIGHT_DEPS_OUT` 与 `FLIGHT_DEPS_FILE` 都在、且 `FLIGHT_GUARD_NESTED` 不为真时，装同样的 open 审计钩子；`atexit` 时把 `sys.modules` 里仓库内模块的 `__file__` 与 open 过的文件追加为 `{"file": FLIGHT_DEPS_FILE, "deps": [...]}`；
   - `SITECUSTOMIZE` 最后从 `sys.path` 去掉自身目录，再尝试 `importlib.import_module("sitecustomize")` 链到仓库自己的那份（失败忽略），不遮蔽仓库原有的 sitecustomize。
4. **`run_test_gate(cmd, root, probe=False, deps=False)`**：
   - 恒加载防护插件：`PYTEST_ADDOPTS` 追加 ` -p flight_guard`，临时目录进 `PYTHONPATH` 最前；
   - `deps=True` 时另加 ` -p flight_deps`，设 `FLIGHT_ROOT` / `FLIGHT_DEPS_OUT`；
   - 返回值新增 `"deps": {"deps": {文件: [路径...]}, "blind": [...], "files": [...], "nodes": {nodeid: outcome}} | None` 与 `"deps_why": str | None`；`deps=False` 时两者恒为 None；
   - 加载失败识别（泛化 `TIER_PLUGIN_FAIL`，覆盖三个 flight 插件的导入失败）→ 去掉三个插件、只带 junit 重跑一次；`probe_why` / `deps_why` 写「防护插件加载失败（包装命令覆写了 PYTHONPATH？），…未测」。
5. **`_pytest_outcomes(..., deps_out=None)`**：`deps_out` 是 dict 时同样加载防护与依赖图插件（argv 里 `-p flight_guard -p flight_deps`），结束后把解析结果写进 `deps_out`（形状同上）。G7 调用不传，行为不变。
6. **锚点池**：新增 `ANCHOR_DIR = "flight-anchors"`、`ANCHOR_KEEP = 20`。
   - `_anchor_write(root, entry)`：复用 `_pool_write` 的原子写与修剪，抽出目录与上限参数，不复制代码；
   - `_anchor_candidates(root, cmd_key, tiers_key, limit=10)`；
   - 条目字段见 design D3，`tiers_key` = 分层文件的 blob id（无分层为 None），`measured` = deps 非 None。
7. **baseline**：
   - 跑全量那一处改为 `run_test_gate(test_cmd, root, probe=tiers is not None, deps=True)`；
   - 有失败且可度量时，`bl["test"]["failed_nodes"]` = deps 结果里 FAILED / ERROR 的 nodeid，排序；
   - 全量结束后写一条锚点：`source: "baseline"`，`commit` = HEAD，`snapshot` = 结束时快照，`cmd_key` 同基线，`failed` = `failed_nodes` 或 []；
   - 区域运行（`run_test_gate(rcmd, root)`）也带 `deps=True`，依赖并入同一条锚点；
   - deps 为 None 时照样写锚点，`measured: false`，并在 warnings 记 `deps_why`；
   - 复用（增量基线）分支不写锚点。
8. 文件头注释补：防护插件、依赖图插件、锚点池的契约各一句。

**verify**：`python3 -m pytest -q tests/test_final_guard.py tests/test_final_deps.py tests/test_tiers_probe.py tests/test_tiers_gate.py tests/test_slice_gate.py tests/test_slice_gate_baseline_preflight.py tests/test_baseline_incremental.py`

**注意**
- 不改 final 的行为（S2 负责）；不改 G7 的结果判定；探针的既有输出形状不变。
- 嵌套会话与外层的判别不得依赖 ppid（design D1 说明了原因）。
- 守护测试做 mutation 自证：
  - 去掉防护插件里 `xmlpath = None` 那一行，`test_nested_pytest_does_not_overwrite_junit` 要变红；
  - 去掉 `sitecustomize` 的写出，`test_full_run_records_dependency_map` 要变红。
- 只用标准库，兼容 Python 3.8；`compileall` 绿。
