# S4 · 文档：/pr-ship 自动修复不询问；增量 final 写进 verify / apply / schema / README

**做什么**：
- `/pr-ship` 评审出 CRITICAL/HIGH 时直接自动修复并 push，不再问询；
- `/opsx-verify`、`/opsx-apply` 与同名 skill、schema 的 tasks instruction、README 写明增量 final。

语义见 `specs/pr-ship-review-autofix` 与 `specs/incremental-final` 的「文档描述增量 final」，以及 design D10、D11。

**owns**
- `template/.claude/commands/pr-ship.md`
- `template/.claude/commands/opsx-verify.md`
- `template/.claude/skills/openspec-verify-change/SKILL.md`
- `template/.claude/commands/opsx-apply.md`
- `template/.claude/skills/openspec-apply-change/SKILL.md`
- `template/openspec/schemas/intent-driven/schema.yaml`
- `README.md`
- `tests/test_incremental_final_docs.py`

**依赖**：无（只写文档；描述的行为由 S1–S3 实现，措辞以 spec 为准）。

**做法**
1. **TDD**：去掉 `tests/test_incremental_final_docs.py` 两条用例的 `XF` 标记，先红后绿。
2. **`pr-ship.md`**：
   - frontmatter description 的「全程至多一次问询」改为「全程不问询」；
   - step 10 标题改为「CRITICAL/HIGH 自动修复（至多 2 轮，不询问）」：
     - 删掉 AskUserQuestion 与「只贴评论交人 / 默认只贴评论」分支；
     - 写明有 CRITICAL/HIGH 就直接修复并 push，不询问；
     - 保留原有修复流程、follow-up 复核、跑满 2 轮仍阻断则停下交人；
   - 收尾复裁一节去掉对「只贴评论」的引用，其余不动；
   - Guardrails 的「全程至多问询 1 次」改为「全程不问询（CRITICAL/HIGH 自动修复至多 2 轮，仍阻断停下交人）」；
   - 「与已有命令的配合」表里的描述同步。
   - `tests/test_template_docs.py::test_pr_ship_single_review` 的其余断言（`gate-report.md`、`evidence.log`、`不重跑测试`、`至多 2 轮`、`model: "<main>"` 至少 2 处、`timeline.py record pr-open`、`review-findings.json`）必须仍成立。
3. **`opsx-verify.md` 与 `openspec-verify-change/SKILL.md`（同改，措辞一致）**：
   - 跑门禁 final 一节写明：final 默认**增量**，以锚点为基准只重跑受影响的测试文件；何时自动全量；`--full` 强制全量；同树沿用（代码树、计划、命令都没变且上次绿就秒回）；
   - 结论里列出 `incremental.mode`。
4. **`opsx-apply.md` 与 `openspec-apply-change/SKILL.md`（同改）**：在「`final 过期` → 重跑 final 再 ship」处补一句：同树会秒回，内容变了走增量。
5. **`schema.yaml` 的 tasks instruction**：在 `gate.checks` 说明之后补 `gate.impacted`（可选）：仓库已有选测命令时配上，增量 final 改由它运行，库经 `GATE_DELTA_FILE` / `GATE_ANCHOR_COMMIT` 交给它改动清单与锚点。
6. **`README.md`**：在门禁相关段落补一小段「增量 final」：锚点池位置、何时全量、`--full`、`gate.impacted`、checks 的三个环境变量。

**verify**：`python3 -m pytest -q tests/test_incremental_final_docs.py tests/test_template_docs.py tests/test_docs_iron_rules.py tests/test_gate_checks_docs.py tests/test_tiers_docs.py`

**注意**
- 命令与同名 skill 必须同改，禁止漂移。
- 不改其他命令的问询规则；`/opsx-apply` 的四种暂停例外不变。
- 改 schema 后跑 `cd template && openspec schema validate intent-driven` 须绿。
- 文档禁日文假名 / 韩文谚文。
