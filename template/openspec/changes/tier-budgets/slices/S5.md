# S5 · flight-doctor.py：[tests] 列出预算与放行

## 做什么

给 `template/.claude/hooks/flight-doctor.py doctor` 的 `[tests]` 一节加几行：各范围的预算对账本里的实际、写了单条上限的区域里超线的条数、放行名单的到期情况。规则原文见 `specs/tier-budgets/spec.md` 的「体检列出预算与放行」。

只读、恒以 0 退出。没有分层文件，或分层文件既没写预算也没有放行条目时，`[tests]` 的输出与现在逐行相同。

## 依赖的接口

见 `slices/_interfaces.md`：

- S1 `test-ledger.py`：`budget(final, base, budgets, scope_of, allow, phase)`——这里以 `phase="baseline"`、`base=None` 调用，得到「眼下这份账本里的全部超线」（都计在 `debt` / `debt_n`）与 `totals`、`allow`。
- S2 `slice-gate.py`：`tier_budgets`、`budget_scope_of`、`allow_view`、`_load_tiers_file`。
- 既有：`load_gate()` 加载 `slice-gate.py`、`load_ledger()` 加载 `test-ledger.py`。

## 怎么做

TDD：`tests/test_budget_doctor.py` 的 2 条骨架现在是红的。

在 `doctor_tests` 里、「未配置测试分层」那一行的判断附近加一段（放在「最近的测试变更」之前）：

1. `<openspec_root>/test-tiers.json` 存在才继续；用 `sg._load_tiers_file(path)` 读，读不出合法的分层文件（返回 `None`）→ 加一行 `  分层文件不合法，预算与放行未列出` 后跳过。
2. `budgets = sg.tier_budgets(tiers)`，`view = sg.allow_view(tiers.get("slow_allow") or {})`。
3. 分层文件里一个 `budget` 键都没有且 `view` 为空 → 不加任何行。
4. 有账本（`best` 不是 `None`）且写了任何 `budget`：`b = tl.budget(led, None, budgets, sg.budget_scope_of(tiers), view, "baseline")`，然后：
   - `b["totals"]` 里每个 `budget` 不是 `None` 的范围一行：`  预算 <范围>：合计 <sec>s / <budget>s`，`over` 为真加「（超预算）」，为 `None` 加「（未判）」；`sec` 用 `%.1f`，预算用 `%g`。骨架断言同一行里有 `unit`、`3.0s / 2s`、「超预算」。
   - 每个写了 `case_sec` 的区域：`one = tl.budget(led, None, {范围: budgets[范围]}, scope_of, view, "baseline")`（只传这一个范围，`debt_n` 与 `debt` 就只属于它）；`one["debt_n"] > 0` 时加一行 `  区域 <范围> 单条上限 <线>s：超线 <n> 条，最慢 <id> <秒>s`（`debt[0]` 是最慢的）。骨架断言同一行里有 `hooks`、「超线 1 条」与那条用例的 id。
5. `view` 非空（不论有没有账本）加一行：`  放行：共 <n> 条 · 已过期 <n> 条（<id>、…）· 14 天内到期 <n> 条 · 无上限 <n> 条`。
   - 数字取自 `tl.budget(...)["allow"]`；没有账本时直接从 `view` 数（`expired` / `soon` / 未过期且 `limit` 为 `None`）。为了少一条分支，可以统一从 `view` 数。
   - 已过期为 0 时不带括号；骨架断言这一行去掉首尾空白后以「放行」开头，含「共 3 条」「已过期 1 条」与过期那条的用例 id、「14 天内到期 1 条」「无上限 1 条」。
6. 文件头注释里 `[tests]` 的说明补半句，并把「只调用 load / summary / parse_segment / segment / _sort_key」那句加上 `budget`。

## 注意

- 整段包在 `doctor_tests` 已有的调用保护里（`doctor()` 里有 `try`）；本片新增的部分自己再包一层 `try`，出错只加一行 `  预算与放行未列出：<原因>`，不要让 `[tests]` 其余内容丢掉。
- `tests/test_flight_doctor_tests.py` 的三条旧用例里被测仓库都没有分层文件，输出必须不变；其中一条把「含 `::` 的行」当作最慢清单，本片新增的行只在有分层文件时才出现，不冲突。
- 骨架第二条的后半：把分层文件换成没有预算、放行为空的版本后，`[tests]` 里不得有含「预算」或「放行」的行——现有各行本来就不含这两个词，别在别处引入。
- 不改 `[tests]` 以外的任何一节。
