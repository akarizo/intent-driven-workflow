# S4 · slice-gate.py：baseline / final 接入预算判定

## 做什么

让 `slice-gate.py baseline` 与 `final` 在落账之后按分层文件的预算判定，把 G13 / G14 并进结论，把摘要放进输出；争抢下降级；把预算与放行相对基线的改动报出来；并修掉一处挡着「层总量」的既有缺陷（只重跑区域的增量 final 把其余用例从锚点与账本里丢了）。规则原文见 `specs/tier-budgets/spec.md` 的「baseline 与 final 按预算判定并在争抢下降级」「只重跑区域的增量 final 不丢其余用例」；取舍见 `design.md` D5、D6、D7、D9、D13。

没有任何范围写 `budget` 时，输出不得多出任何东西（骨架里有一条不带 xfail 的护栏钉着）。

## 依赖的接口

见 `slices/_interfaces.md`：

- S1 `test-ledger.py`：`budget(...)`、`budget_changes(...)`；`render` 已认 `d["budget"]`。
- S2 `slice-gate.py`：`tier_budgets(tiers)`、`budget_scope_of(tiers)`、`allow_view(allow, today)`；分层文件的形状校验已接受新字段。
- 既有：`_ledger_mod()`、`_ledger_commit(...)`（返回 `(账本 | None, 警告 | None)`）、`_time_verdicts(failed, warnings, lock_info)`、`_tiers_path(change_dir)`、`_change_rel`、`git(root, …)`。

## 怎么做

TDD：`tests/test_budget_gate.py` 的 8 条骨架现在是红的（第 9 条 `test_no_budget_keeps_output_unchanged` 是护栏，现在就绿，做完仍须绿）。

1. **`_time_verdicts`**：降级的前缀从一个扩成三个——`G10 slow unit test`、`G13 slow integration test`、`G14 tier budget`。其余不动（只在 `state == "timeout"` 时降级，尾注原文不变）。
2. **`_budget_judge(root, name, tiers, led, phase, lock_info, base=None, base_commit=None)`** → `(failed, warnings, 摘要 | None)`：
   - `tiers` 为 `None`，或分层文件里一个 `budget` 键都没有（遍历 `tier_parts(tiers)` 各部件的 `unit` 与各区域）→ 返回 `([], [], None)`；
   - 写了预算而 `led` 为 `None` 或 `_ledger_mod()` 是字符串 → `([], ["预算未判：测试账本不可用（<原因>）"], None)`；
   - 否则调用 `mod.budget(led, base, tier_budgets(tiers), budget_scope_of(tiers), allow_view(tiers.get("slow_allow") or {}), phase)`；
   - `phase == "final"` 且给了 `base_commit`：
     - `git show <base_commit>:<分层文件相对 git 顶层的路径>` 取基线时的分层文件；取不到（当时没有这个文件）、解析不了、形状不合法 → 不比；
     - `lines = mod.budget_changes(tier_budgets(旧), tier_budgets(新), 旧的 slow_allow, 新的 slow_allow)`；
     - `lines` 非空 → 警告 `预算变更（相对基线 <commit 前 10 位>）：<各行以「；」相连>`，摘要加 `"changes": lines`；为空时摘要里 `"changes": []`；
   - `failed, warnings = _time_verdicts(结果的 failed, 结果的 warnings, lock_info)`；
   - 摘要 = 结果去掉 `failed` / `warnings` 两个键；
   - 整个函数体包在 `try` 里：任何异常 → `([], ["预算未判：%s: %s" % (type(e).__name__, e)], None)`。
3. **final 接入**。两处落账之后各接一次（部件形态那一处与其余分支共用的那一处）：
   - `base = lmod.load(root, name, "baseline")`（`lmod` 不可用时 `None`）；
   - `f, w, bsum = _budget_judge(root, name, tiers, led, "final", hold.info, base, (baseline or {}).get("commit"))`；
   - `failed.extend(f)`、`warnings.extend(w)`——必须在 `result = {…"ok": not failed…}` 之前，所以接在落账那一段里，不要挪到后面拼 `tests` 的地方；
   - 后面拼 `result["tests"]` 的地方：`bsum` 不是 `None` 时 `result["tests"]["budget"] = bsum`，并在存 `delta.json` 之前 `d["budget"] = bsum`（`d` 为 `None` 时只放进 `tests`）。`bsum` 为 `None` 时两处都不出现这个键。
   - 没有落账的 final（G7 红、选测复核未过、同树沿用）不判预算。
4. **baseline 接入**。`led` 落账、`bl["ledger"] = lmod.summary(led)` 那一段之后，算锚点的 `measured` 之前：
   - `f, w, bsum = _budget_judge(root, name, tiers, led, "baseline", hold.info)`；
   - `reasons.extend(f)`、`warnings.extend(w)`；`bsum` 不是 `None` 且 `bl` 有 `ledger` 时 `bl["ledger"]["budget"] = bsum`；
   - 位置在 `bl["test_ok"]` 算完之后，所以 G14 不影响 `test_ok`；它让基线红（`bl["ok"]` 为假），与 G10 一样。
5. **只重跑区域的增量 final 不丢其余用例**（既有缺陷，挡着层总量）：
   - 现象：有分层文件、Δ 只命中区域文件时，`run_sel` 为空（不起 pytest），而 `_anchor_forward(root, anchor, rerun, d, fails, outcomes)` 的第三个参数是含区域文件的 `rerun`；函数里 `if _anchor_has_nodes(old) and (d or not sel)` 因 `d` 为空、`sel` 非空而不成立，`nodes` 被清成 `{}`，随后只并回区域的用例。结果：新锚点与收口账本里没有单元层用例，`tests.delta.unknown` 把它们记成「未重测」。
   - 修法：`_anchor_forward` 加一个带缺省值的参数（例如 `ran=None`），表示「本次有没有真的起 pytest 重跑」；`nodes` 的条件改成 `d or not (sel if ran is None else ran)`；`cmd_final` 那一处调用传 `ran=bool(run_sel)`。其余调用点（baseline 经锚点增量等）不传，行为不变。
   - 这与同一段里 `nodes_ok = _anchor_has_nodes(anchor) and (bool(d) or not run_sel)` 的口径一致。
   - 骨架 `test_region_only_rerun_keeps_unit_cases` 断言：收口账本里单元层用例 `m == 0`、新锚点 `nodes` 含它、`tests.delta.unknown == 0`。
6. 文件头注释：baseline / final 的说明各补一句预算判定（G13 / G14、依赖测试账本、`timeout` 时降为警告）。

## 注意

- **判定顺序**：G13 / G14 的文本由 `test-ledger.py` 给出，本片只转发；不要在 `slice-gate.py` 里重拼。
- **`test_budget_failure_does_not_fail_gate`** 用不含 `test-ledger.py` 的 hooks 副本：区域写了 `case_sec`，final 必须 `ok`、`failed` 为空，`warnings` 里有一条以「预算未判」开头（另有一条「测试账本未写…」是既有的）。
- **`test_contended_run_downgrades_budget_verdicts`**：baseline 在 `timeout` 下，G14 不在 `reasons` 里，而在 `warnings` 里并含「降为警告」——`_time_verdicts` 的尾注已经含这四个字。
- **`test_final_reports_budget_changes`**：区域 `hooks` 的 `case_sec` 30 → 300。警告须以「预算变更」开头并含 `hooks`、`30s → 300s`、「放宽」（后三样来自 `budget_changes` 的行）。
- **`test_parts_unit_total_judged_per_part`**：部件形态的 baseline。范围是 `py/unit`，G14 文本里是「部件 py 的单元层」。部件形态的落账点（`mode="parts"`）同样要接。
- **`test_debt_keeps_baseline_and_final_green`**：baseline 的「老债」警告要进 `gate-baseline.json` 的 `warnings`——接入点在 `if warnings: bl["warnings"] = warnings` 之前即可。
- `tests/test_gate_checks_baseline.py::test_no_checks_behavior_unchanged` 钉着 final 输出 JSON 的顶层键集合：`budget` 放在 `tests` 里面，不加顶层键。
- 切片门禁（`cmd_gate`）不判预算，不要给它加调用。
- 本片之后 S7 还要改 `slice-gate.py`（部件区域采集、`_lock_expect_sec`），两处都别顺手动。
