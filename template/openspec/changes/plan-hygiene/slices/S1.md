## 怎么做

TDD：先确认 `tests/test_plan_hygiene_baseline.py` 的 8 条骨架是红的（strict xfail），再写实现。

1. **解析函数**（D1），放在 `load_baseline` 旁边：
   ```python
   def suite_sec(change_dir, data=None):
       """最近一次已知的全量耗时：gate-baseline.json（含运行标记）顶层 full_suite_sec → 计划里旧的 gate.full_suite_sec → None；bool 不算数值。"""
   ```
   - `load_baseline` 读不到 / 不是对象时按没有处理，不抛。
   - `data` 为 `None` 时不读计划（调用方没有计划就只看基线）。
2. **`cmd_baseline`**：
   - **`gate.test` 缺失即停**：`gate.test` 不是非空字符串 → `die`，文字含 `gate.test` 与「须显式写出」，在写运行标记之前。删掉这里的 `detect_test_cmd` 回退与 `gate["test"] = test_cmd` 回填。`detect_test_cmd` 函数本身保留（`cmd_final` 与 `_builtin_report` 还在用）。
   - **开跑前**取 `prev = suite_sec(args.change_dir, data)`；运行标记写成 `{"running": True, "pid", "started"}`，`prev` 不为 `None` 时再加 `"full_suite_sec": prev`。
   - **结束时**写 `bl["full_suite_sec"]`：
     - 全量（`hit is None`）：本次全量墙钟。就是现在赋给 `gate["full_suite_sec"]` 的那个数（部件形态 = `bl["test"]["sec"]`）；把这两处对 `gate[...]` 的内存赋值改成局部变量。
     - 增量：`prev` → 候选的 `full_suite_sec` → 候选的 `test.sec`（候选是锚点包装时后两者都取不到，就是 `None`，字段写 `None`）。
   - **删写回**：去掉 `cg[...]` 的三处赋值与 `save_plan(args.change_dir, cur)`；`cur = load_plan(...)` 与紧随其后的 `plan_sha(cur) != sha0` 判定保留。`save_plan` 再无调用方，连同定义一起删。
   - **基线池条目**多存 `full_suite_sec`（`_pool_write` 的键清单），跨 change 复用时候选才有这个值。
3. **读取方**：
   - `_die_running_baseline`：估时改用 `suite_sec(change_dir, data)`（运行标记此刻就是 `gate-baseline.json`）。
   - `_g7_timeout(gate)`：调用处拿不到 change 目录。做法二选一，取 diff 小的：
     - 在 `cmd_gate` / `cmd_final` / `cmd_baseline` 读完计划后，把 `suite_sec(...)` 的结果放进内存里的 `gate["full_suite_sec"]`（现在没有任何地方会把它落盘）；
     - 或给 `_g7_timeout` 加一个可选参数并改调用链。
     无论哪种，`FLIGHT_G7_TIMEOUT` 环境变量的优先级不变，缺省 600 不变。
   - `flight-doctor.py` 的读取留给 S3，本片不动它（它现在读旧字段，过渡期仍可用）。
4. **gitlink 进快照**（D2），`_snapshot`：遍历前取一次 `_gitlinks(root)`；路径是目录且在其中时，记 `_sub_head(root, p)`（子仓未就绪或取不到时记索引里的 sha）。其他目录照旧不记。`_delta` 不改。
5. **文件头注释**：第 32 行附近「耗时写回 slices.json.gate.full_suite_sec」改成与新行为一致；`plan_sha` 的 docstring 里「owns / 耗时不影响」保留即可。
