# S3 · 判定器：final 运行检查（G9）

**做什么**：`slice-gate.py final` 在 G7 绿时、全量判定之后运行每个检查的 `final`，按退出码记 G9；先核对基线记录；G7 红时不跑并警告。语义见 `specs/gate-paired-checks` 的「final 运行检查并以 G9 判定」「检查命令的运行契约」与 design D8。

**owns**
- `template/.claude/hooks/slice-gate.py`
- `tests/test_gate_checks_final.py`

**做法**
1. 逐条去掉 `tests/test_gate_checks_final.py` 里 5 条 xfail 标记，先红后绿（TDD）。
2. **位置**：`cmd_final`（`:1255`）里，全量块（`:1276-1287`）之后、组装 `result` 之前。
3. **G7 红**（`v7` 非空）：`checks` 非空时 `warnings` 追加 `G9 检查未跑：G7 已红，scenario 全绿后重跑 final`；原有 `G2 全量未跑：…` 那条不动。不运行任何检查。
4. **G7 绿**：按 `gate.checks` 顺序逐个：
   - `base = (baseline or {}).get("commit")`，`rec = ((baseline or {}).get("checks") or {}).get(name)`；
   - `base` 为空，或 `baseline` 命令非空而 `rec` 不是 dict / `rec["exit"] != 0` / `rec["cmd"] != 当前 baseline 命令` → `failed` 加 `G9 check <name>：基线缺记录或与计划不符，重跑 baseline`，跳过；
   - 否则 `cdir = _check_dir(...)`，`os.makedirs(cdir, exist_ok=True)`（不清空）；环境 `_check_env("final", change, base, cdir)`；`_run_check(final_cmd, root, env, timeout_sec)`；`_check_log(cdir, "final", out)`；
   - 超时 → `G9 check <name>：超时 N 秒；日志 …` + `_tail(out, 20)`；rc 非 0 → `G9 check <name>：exit N；日志 …` + `_tail(out, 20)`；
   - 全量红时也照跑（不看全量结果）。
5. `change` 名用 `os.path.basename(os.path.realpath(args.change_dir))`，与 baseline 相同。
6. 文件头注释的 final 说明补一句：最后运行 `gate.checks` 的 final（G9）。

**依赖切片的接口**（来自 S2）
- `_check_dir(root, change, name)`、`_run_check(cmd, root, env, timeout) -> (rc, out, sec, timed_out)`、`_check_env(phase, change, base_commit, cdir)`、`_check_log(cdir, phase, out)`；
- `gate-baseline.json` 的 `checks.<name> = {exit, sec, cmd, key[, reused][, timed_out]}`；
- 测试夹具：`tests/test_gate_checks_baseline.py` 的 `CHECK`、`setup_checks`、`set_checks`、`parity`、`check_dir`、`runs`、`final_json`（只读复用，不改该文件）。

**verify**：`python3 -m pytest -q tests/test_gate_checks_final.py tests/test_gate_checks_baseline.py tests/test_slice_gate_final.py tests/test_slice_gate.py tests/test_slice_gate_baseline_preflight.py`

**注意**
- 没有 `gate.checks` 时 final 的输出与现在完全相同（`test_no_checks_behavior_unchanged` 守护）。
- `ship` 不改：它读 final 行的 ok。
- 守护测试做 mutation 自证：把基线核对、G7 红跳过、全量红照跑逐一改坏，对应断言要变红。
- `compileall` 绿；只用标准库；兼容 Python 3.8。
