# S1 · 判定器：lint 校验检查配置与仓库默认检查

**做什么**：`slice-gate.py lint`（以及 preflight 里同一份计划校验）认识 `gate.checks` / `gate.checks_skip`，并按 change 目录找仓库默认检查文件对账。语义见 `specs/gate-paired-checks` 第一条 Requirement 与 design D1、D9。本片不运行任何检查。

**owns**
- `template/.claude/hooks/slice-gate.py`
- `tests/test_gate_checks_lint.py`

**做法**
1. 逐条去掉 `tests/test_gate_checks_lint.py` 里 4 条 xfail 标记，先红后绿（TDD）。2 条护栏（`test_lint_accepts_valid_checks`、`test_lint_accepts_default_check_skipped_with_reason`）原本就不带标记，改完须仍绿。
2. **签名**：`lint_plan(data, change_dir=None)`。`change_dir` 为 None 时不读仓库默认文件；`cmd_lint`（`:887`）与 `cmd_preflight`（`:1479`）传 `args.change_dir`。其他调用方不变。
3. **形状规则**（每条违规进 `errors`，文本以 `checks:` 开头并点名对象）：
   - `gate.checks` 存在时须是 list，每项是 dict；
   - 字段只允许 `name` / `baseline` / `final` / `timeout_sec`，多出的字段点名检查与字段；
   - `name` 是 str 且 `re.fullmatch(r"[a-z0-9-]+", name)`；重复的 name 报一次；
   - `final` 是去空白后非空的 str；
   - `baseline` 缺省、None，或去空白后非空的 str；
   - `timeout_sec` 缺省，或 `int` / `float`（排除 `bool`）且 `> 0`；
   - `gate.checks_skip` 存在时须是 dict；值须是去空白后非空的 str；键不得同时是 `gate.checks` 的 name。
4. **仓库默认检查**（D9）：
   - 路径 `os.path.join(os.path.dirname(os.path.dirname(os.path.abspath(change_dir))), "gate-checks.json")`；
   - 不存在 → 不触发；
   - 读不出、JSON 不合法、不是 list、元素不是 dict、`name` 不合法或重复 → 一条 `checks: 仓库默认检查文件 <路径> 无法解析：<原因>`；
   - 合法时，每个默认 name 不在 `gate.checks` 的 name 里、也不是 `checks_skip` 的键 → `checks: 仓库默认检查 <name> 未出现在 gate.checks，也没有在 gate.checks_skip 写理由`。
5. 文件头注释的子命令说明补一行 lint 的检查规则；`main()` 不用改。

**verify**：`python3 -m pytest -q tests/test_gate_checks_lint.py tests/test_slice_gate.py tests/test_slice_gate_baseline_preflight.py`

**注意**
- 不改 `plan_sha`、`cmd_baseline`、`cmd_final`（S2 / S3 的事）。
- 没有 `gate.checks`、没有默认文件时 `lint_plan` 的返回与现在完全相同。
- 守护测试做 mutation 自证：把任一条判定改坏，对应断言要变红。
- `compileall` 绿；只用标准库；兼容 Python 3.8。
