# S2 · 判定器：检查运行函数、baseline 运行与记录检查、plan_sha 并入检查

**做什么**：baseline 在每片 verify 之后运行每个 `baseline` 非空的检查并记录；沿用照 D10；`plan_sha` 在配置了检查时追加 `[name, baseline]`。语义见 `specs/gate-paired-checks` 的「检查命令的运行契约」「baseline 运行并记录检查」「preflight 按计划对账检查」「未配置检查时行为不变」与 design D2–D7。

**owns**
- `template/.claude/hooks/slice-gate.py`
- `tests/test_gate_checks_baseline.py`

**做法**
1. 逐条去掉 `tests/test_gate_checks_baseline.py` 里 8 条 xfail 标记，先红后绿（TDD）。2 条护栏（`test_preflight_ignores_check_final_edit`、`test_no_checks_behavior_unchanged`）不带标记，改完须仍绿。
2. **共用目录**（D3）：新增 `CHECKS_DIR = "flight-gate-checks"` 与 `_check_dir(root, change, name)`，git common dir 的解析照 `_pool_dir`（`:1708`），返回绝对路径 `<common>/flight-gate-checks/<change>/<name>`。
3. **运行函数**（D2）：新增 `_run_check(cmd, root, env, timeout)` → `(rc, out, sec, timed_out)`：
   - `subprocess.Popen(cmd, shell=True, cwd=root, env=env, stdout=PIPE, stderr=STDOUT, text=True, start_new_session=True)`；
   - `communicate(timeout=timeout)`（`timeout` 为 None 即不设）；`TimeoutExpired` → `os.killpg(p.pid, 9)`（OSError 忽略）→ `communicate()` 收尾；
   - 照 `_pytest_outcomes`（`:775-790`）的写法；`Popen` 抛 OSError 时按 rc 127、输出为错误文本处理。
4. **环境与日志**（契约、D4）：新增 `_check_env(phase, change, base_commit, cdir)` 在 `os.environ` 副本上设 `GATE_PHASE` / `GATE_CHANGE` / `GATE_BASE_COMMIT` / `GATE_CHECK_DIR`；新增 `_check_log(cdir, phase, out)` 覆盖写 `cdir/.gate-<phase>.log`，返回日志路径，OSError 时返回 `None` 与错误文本。红的提示：首行结论 + `；日志 <路径>`（写失败为 `；日志未能写入：<错误>`），再接 `_tail(out, 20)`。S3 复用这三个函数。
5. **baseline**（D5、D6）：在 verify 循环（`:1383-1396`）之后、D6 的 `s1 = _snapshot(...)`（`:1400`）之前：
   - `checks = gate.get("checks") or []`；非空时 `bl["checks"] = {}`；
   - 逐个 `baseline` 非空的检查：`kkey = cmd_key(root, change_rel, bcmd)`；
   - **沿用**：`strict_delta == []`（`:1356-1358` 已算好，只在 `hit is not None and src is own` 时为列表）且 `kkey` 非空、旧记录 `old["checks"][name]` 是 dict、有 `exit`、`cmd == bcmd`、`key == kkey`、`os.path.isdir(cdir)` → 记 `{exit, sec, cmd, key, reused: True}`，不运行、不清空；
   - **实跑**：`shutil.rmtree(cdir, ignore_errors=True)`，`os.makedirs(cdir)`；环境 `GATE_BASE_COMMIT=bl["commit"]`；超时取 `timeout_sec`；记 `{exit: rc, sec, cmd, key}`，超时另加 `timed_out: True`；
   - **红**：超时 → `reasons` 加 `check <name> 在基线上超时（N 秒）；日志 …` + 末尾 20 行；rc 非 0 → `check <name> 在基线上红（exit N）；日志 …` + 末尾 20 行；
   - 入池（`:1429-1431`）的字段白名单不动，池条目自然不含 `checks`。
6. **plan_sha**（D7，`:241`）：`checks = gate.get("checks")`；为 list 且非空时在 `key` 末尾追加 `[[c.get("name"), c.get("baseline")] for c in checks if isinstance(c, dict)]`；否则 `key` 与现在逐元素相同。
7. preflight 不改代码：红由 `bl.ok`，过期由 `plan_sha`。
8. 文件头注释的 baseline / preflight 说明补检查相关的一句；JSON 契约注释补 `checks`。

**依赖切片的接口**（来自 S1）
- `lint_plan(data, change_dir=None)`；preflight 里已对 `gate.checks` 做形状校验，本片可以假设 `name` 合法、`final` 非空、`timeout_sec` 为正数或缺省。

**verify**：`python3 -m pytest -q tests/test_gate_checks_baseline.py tests/test_baseline_incremental.py tests/test_baseline_pool.py tests/test_baseline_skip.py tests/test_slice_gate.py tests/test_slice_gate_baseline_preflight.py`

**注意**
- 没有 `gate.checks` 时：不建目录、不出现 `bl["checks"]`、`plan_sha` 不变、timeline 行不变。
- 只能沿用本 change 的旧基线（`src is own`）；跨 change 候选、`--full` 一律实跑。
- 不改 `cmd_final`（S3 的事），不改 S1 的测试文件。
- 守护测试做 mutation 自证：把沿用条件、清空目录、超时整组结束、`plan_sha` 追加逐一改坏，对应断言要变红。
- `compileall` 绿；只用标准库；兼容 Python 3.8。
