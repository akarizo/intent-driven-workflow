# S1 · 门禁展开：gitlink → 子仓内文件、G6 gitlink、G8 带子仓、门禁绿锚定子仓提交

## 做什么

让 `slice-gate.py gate` 按子仓内的真实文件判 G3 / G6 / G8 / GWT。规则原文见 `specs/submodule-gate-expansion/spec.md`，决策见 `design.md` D3。本片**不做**：
- 隔离 worktree 填充（S2）；
- 快照（S2）；
- `merge`（S3）；
- 文档（S4）。

用例都在 change 家里跑（子仓已初始化），不依赖 S2。

## 怎么做（`template/.claude/hooks/slice-gate.py`）

1. **`_gitlinks(root)`** → `{路径: 索引里的 sha}`：`git ls-files -s -z` 中 mode 为 `160000` 的条目。辅助函数 `_sub_ready(root, p)` = `os.path.exists(os.path.join(root, p, ".git"))`。`_sub_has(root, p, sha)` = 在子仓里 `cat-file -e <sha>^{commit}` 是否为 0。
2. **`changed_files(root, base)`**：签名与返回形状不变，在现有结果上展开 gitlink：
   - **已提交**：`base != head` 时，读 `git diff --raw -z --no-renames base..HEAD`。条目格式是 `:<旧mode> <新mode> <旧sha> <新sha> <状态>\0<路径>\0`。旧 / 新 mode 任一为 `160000` 时，看三个条件：两侧都是 160000、`_sub_ready`、两个 sha 都 `_sub_has`。
     - 三个条件都满足 → 从 committed 去掉 P，加入 `P/` + `git -C P diff --name-only -z --no-renames <旧> <新>` 的各项；
     - 否则保留 P（G6 会点名）。
   - **未提交**：父仓 porcelain 结果里属于 `_gitlinks` 且 `_sub_ready` 的 P → 从 uncommitted 去掉 P，加入两部分：
     - `P/` + `git -C P status --porcelain -z --untracked-files=all` 的路径（改名项取新路径，跳过随后的原路径）；
     - 子仓 HEAD ≠ `git rev-parse HEAD:P`、且两者都 `_sub_has` 时，再加 `P/` + `git -C P diff --name-only -z <HEAD:P> <子仓 HEAD>`。
   - 展开结果同样过 `is_bytecode` 过滤（子仓里跑 pytest 会产生 `tests/__pycache__`）。
   - 没有 gitlink 时一行逻辑都不进，输出与改前一致。
3. **`G6 gitlink`**：`cmd_gate` 里，在现有 `ownership_violations` 之后，对每个 `_gitlinks` 中 `_sub_ready` 的 P，若子仓 HEAD ≠ `HEAD:P`（`HEAD:P` 取不到，如新增 submodule，视同不一致），追加：
   `G6 gitlink: <P> 的检出 <子仓HEAD[:10]> 未记录进父仓 HEAD（父仓记录 <HEAD:P[:10] 或 无>；git add <P> 后并入本切片 commit）`
4. **`added_lines(root, base)`**：git diff 参数改为 `diff --unified=0 --submodule=diff base..HEAD`。解析逻辑不动：git 原生输出 `+++ b/<P>/<文件>`，`Submodule <P> a..b:` 行不以 `+` 开头，会被跳过。
5. **锚定**：`cmd_gate` 门禁绿（`result["ok"]`）时，对 `base..HEAD` raw diff 里新 mode 为 160000、且 `_sub_ready` 的 P，执行 `git -C P update-ref refs/flight-sub/<change 名>/<S> <新 sha>`。change 名取 `os.path.basename(change_dir)`，与 `_ckpt_ref` 同口径。失败只追加 warning，不改 ok。
6. 子仓里的 git 一律用 `subprocess.run(["git", "-C", ...])` 或 `cwd=<root>/<P>`，不经 shell。`git()` 帮手会 strip 掉 porcelain 的前导空格，读 porcelain / raw 时用 `_git_raw` 或直接 `subprocess.run`（参见 `changed_files` 现有注释）。
