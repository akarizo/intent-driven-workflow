# S1 · slice-gate.py reap：飞行收口回收本次飞行的临时 worktree

## 做什么

在 `template/.claude/hooks/slice-gate.py` 新增子命令 `reap --change-dir DIR`。在 change 家（运行时的 cwd，也就是 git 顶层 `root`）运行，回收本次飞行留下的执行体临时 worktree：

- 已落地的直接回收；
- 作废的尝试先归档再回收；
- 恒以 0 退出，打印 JSON，并写 timeline 事件 `reap`。

规则原文见 `specs/flight-close-reap/spec.md` 的前三条 Requirement（共 7 个 scenario），决策见 `design.md` D1–D6。

## owns

- `template/.claude/hooks/slice-gate.py`
- `tests/test_close_reap.py`（7 条 strict-xfail 骨架已写好，断言是真实的；实现后去掉 `@pytest.mark.xfail` 标记）

## 依赖的接口（本文件已有，直接复用，不要改它们的行为）

- `_reap_one(root, wt, warnings)` → bool（`slice-gate.py:5463`）：
  - 只允许飞行记录 / 切片标记 / 未跟踪字节码三类改动；
  - 先归还借出的子仓；
  - 丢弃三类改动后，用不带 `--force` 的 `git worktree remove` 删除；
  - 不满足条件时往 `warnings` 追加「未回收 …」并返回 False。
- `_reap(...)`（`slice-gate.py:5506`）里删分支的写法：分支 ref 仍等于原 HEAD 时 `git branch -d`，失败只告警。
- `_flight_dirt(xy, path)`、`_status_entries(wt)`、`_gitlinks(wt)`、`_drop_untracked(base, paths)`、`_run_git(root, *args)`、`_first_line(text, default)`、`MARKER`、`FLIGHT_RECORDS`、`is_bytecode`。
- `timeline_record(change_dir, event, note)`。
- change 名取法同 `_ckpt_ref`：`os.path.basename(os.path.abspath(change_dir).rstrip(os.sep))`。
- argparse 注册方式见 `slice-gate.py:7310` 起的 `sub.add_parser(...)`。文件头部注释的子命令清单里补一行 `reap`。

## 怎么做（TDD：先跑 verify 看 7 条红）

1. **入口**：`cmd_reap(args)`。`root = git rev-parse --show-toplevel`，失败或 `args.change_dir` 不存在 → 打印 `{"ok": true, "reaped": [], "archived": [], "kept": [], "freed_kb": 0, "warnings": [<原因>]}`，退出 0。
   整个函数包一层 `try`，任何异常都进 `warnings`，恒 `return 0`。
2. **枚举**：解析 `git worktree list --porcelain`。跳过以下几类：
   - 第一块（主 worktree）；
   - `realpath == realpath(root)` 的；
   - `bare`；
   - 目录已不存在的。
3. **归属（design D2）**：满足任一条即属于本次飞行，否则跳过，不进任何列表。
   - (a) `wt/.openspec-slice` 能按 JSON 读出，且 `basename(change_dir)` 等于本 change 名；
   - (b) `_status_entries(wt)` 里有路径的倒数第三段是 `changes`、倒数第二段是本 change 名、最后一段属于 `FLIGHT_RECORDS`。
4. **锁定**：porcelain 块里有 `locked` → `kept.append({"path": wt, "why": "已锁定"})`，跳过。
5. **自有子仓克隆（D5）**：`_gitlinks(wt)` 里的路径 P 满足以下两条时，`kept` 写「含自有子仓克隆 P，交 /clean-after-merged」，跳过：
   - `wt/P/.git` 存在；
   - 它不是从 change 家借出的子仓 worktree。判法：`git -C wt/P rev-parse --git-common-dir` 不在 `root/P` 的 git common dir 之下，且等于或位于 `wt` 自己的 git-dir（`git -C wt rev-parse --git-dir`）之下。

   借出的子仓交给 `_reap_one` 处理。
6. **统计**：删除前统计磁盘占用：遍历 `wt` 下所有文件（不跟随符号链接），累加 `st_blocks * 512`，没有 `st_blocks` 时用 `st_size`，换算为 KB。
7. **已落地**：`git merge-base --is-ancestor <wt HEAD> <root HEAD>` 成立 → 调 `_reap_one(root, wt, warnings)`。
   - 成功 → `reaped.append(wt)`，累加占用；分支照 `_reap` 的写法 `-d`。
   - 失败 → `kept.append({"path": wt, "why": warnings 里最后一条关于它的原因})`。
8. **作废尝试（D4）**：其余情况。
   1. `entries = _status_entries(wt)`，`keep = [p for xy, p in entries if not _flight_dirt(xy, p)]`，排除 gitlink 路径本身。
   2. `keep` 为空 → `tip = wt HEAD`。
   3. `keep` 不为空 → 建临时索引：
      - 先在 `tempfile` 里建一个路径，环境变量 `GIT_INDEX_FILE` 指向它（只对这几次 git 调用生效）；
      - `git -C wt read-tree HEAD`；
      - `git -C wt add -A -- <keep 里的路径>`。会被 `.gitignore` 忽略的不会进来，这是期望行为。
      - `tree = git -C wt write-tree`；
      - `tip = git -C wt commit-tree <tree> -p HEAD -m "attic: <目录名> 的未提交改动（reap 归档）"`。
   4. `ref = "refs/flight/<change>/attic/<basename(wt)>"`。如果该 ref 已存在且不等于 `tip`，改用 `<ref>-<HEAD 前 7 位>`。然后 `git update-ref <ref> <tip>`。
   5. 丢弃 `keep`：已跟踪的 `git -C wt checkout -- <路径>`，未跟踪的用 `_drop_untracked`。
   6. 调 `_reap_one(root, wt, warnings)`：
      - 成功 → `reaped.append(wt)`，`archived.append({"path": wt, "ref": ref})`。分支不删（未合入，`-d` 必拒）。
      - 失败 → `kept` 写原因。ref 已写入，不回滚。
9. **输出**：
   - `freed_kb` 取已删目录占用之和，整数。
   - `timeline_record(args.change_dir, "reap", "回收 %d 个 · 释放 %.1f MB · 归档 %d 个 · 保留 %d 个" % (...))`，计数为 0 也写。
   - stdout 打印 `{"ok": true, "reaped", "archived", "kept", "freed_kb", "warnings"}`（`ensure_ascii=False`）。退出 0。
10. 测试全绿后去掉 7 个 xfail 标记；`verify` 里另两组既有测试（`test_merge_reap.py`、`test_slice_gate.py`）必须保持绿。

## 注意

- 测试的 change 家就是 `git_repo` 本身（主 worktree 检出 `worktree-c`）。所以「跳过主 worktree」与「跳过 root」在测试里是同一间，实现两条都要有。
- 不得使用 `--force`、`git branch -D`；不得删除没有飞行证据的 worktree。
- 不要改 `_reap` / `_reap_one` 的既有行为（`tests/test_merge_reap.py` 钉住）。
