## 依赖的接口（来自 S1、S2，已合回）

- S1：`python3 .claude/hooks/slice-gate.py reap --change-dir openspec/changes/<name>`。
  - stdout 是 JSON：`{ok, reaped, archived:[{path, ref}], kept:[{path, why}], freed_kb, warnings}`，恒 exit 0；
  - 同时写 timeline 事件 `reap`，备注 `回收 N 个 · 释放 X MB · 归档 M 个 · 保留 K 个`；
  - 作废尝试归档到 `refs/flight/<change>/attic/<目录名>`，可用 `git worktree add <路径> <ref>` 找回。
- S2：`merged-cleanup.py` 的原因标记新增：
  - `landed: 已合进本地分支 <B>`（`.claude/worktrees/` 下被 merge 进其他分支的）；
  - `dead-attempt: <C> …`（属于已落地 / 已归档 change 的作废尝试；有分支 safe，游离 HEAD manual）。
