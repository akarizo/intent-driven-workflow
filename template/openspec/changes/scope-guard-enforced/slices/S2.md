# S2 · 内建提供方与 final 精度：_full_triggers、计划期预测、声明文件排除、shell 静态闭包

## 做什么

1. 让 final 的全量判定与内建提供方的计划期预测共用一套触发项规则。
2. 工作流声明文件不再触发「依赖图没见过的非 Python 文件 → 全量」。
3. 测试依赖里的 shell 脚本做静态闭包，计入依赖。

规则原文见 `specs/builtin-scope-precision/spec.md`，决策见 `design.md` D5–D7。

## 怎么做（`template/.claude/hooks/slice-gate.py`，签名见 `_interfaces.md`）

1. **`_full_triggers(...)`**：把 `_full_why`（现 `:4268`）的规则改写成「收集全部触发项」：
   - **文件类**：全局文件、依赖图没见过的非 Python 文件，触发项是路径；
   - **代码类**：没锚点 → `final:no-anchor`；基线有预存红但缺 `failed_nodes` → `final:baseline-missing-failed-nodes`；`gate.test` 无法等价复现 → `final:gate-test-unreproducible`；
   - `_full_why` 改为由第一条触发项拼出与现在**逐字相同**的原因文字（`手动要求 --full` / `没有可用锚点（…）` / `Δ 含全局文件：…` / `Δ 含未被任何用例触及的非 Python 文件：…` 等），现有测试的 `full_why` 断言不得变；
   - `impacted=True` 时只看 `--full`、锚点与全局文件，与现在相同。
2. **声明文件排除**（D6）：
   - 「见过的文件」判定跳过 `_decl_rels(root, change_dir)`（`<openspec 根>/gate-scope.json`、`<openspec 根>/gate-checks.json`）、`tier_rel`，以及以 `.claude/` 开头的路径；
   - 全局文件规则不受影响；
   - ⚠ 不排除整个 openspec 根：本仓库 `template/openspec` 的种子由 `install.sh` 经 bash 拷贝，测不到依赖。
3. **`_shell_closure(root, files)`**（D7、spec「shell 静态闭包计入依赖」）：
   - 识别：后缀 `.sh` / `.bash`，或首行 `#!` 指向 sh / bash / zsh / dash。
   - 逐行解析，跳过注释：
     - dirname 四种形态（含引号变体）替换为脚本目录的绝对路径；
     - 被赋予这些形态（含 `$(cd … && pwd)` 包裹）的变量，其 `$V` / `${V}` 同样替换；
     - 切出路径记号，先按脚本目录、再按 git 顶层解析，只保留存在的仓库文件；
     - 文件名含未解析 `$`、但目录可解析时，取该目录同后缀的全部文件；
     - 目录部分含未解析的 `$(…)`、`$VAR` 时，**不猜**，跳过（护栏 `test_unresolvable_shell_reference_stays_full`）；
     - 新到达的 shell 脚本递归解析，防环。
   - 用在两处：
     - `_final_select`：对每个测试文件，`deps ∪ closure(deps)` 与 Δ 相交即选中；
     - `_full_triggers`：见过的文件 = 全部 deps ∪ closure。
4. **`_builtin_report(root, change_dir, data, phase)` 真实实现**（D5）：
   - **预测 Δ**：`git ls-files` 中匹配任一 owns glob 的文件（用现有 `glob_match`）。
   - **触发项**：
     - 全局文件；
     - `final:gate-test-unreproducible`（复用 `_full_why` 里的复现判定）；
     - 「没见过」的非 Python 文件。
   - **锚点**：
     - lint / baseline 取锚点池里 `cmd_key` / `tiers_key` 匹配、`measured` 为真的最新一条；
     - preflight 用 `_pick_anchor` 对当前树取；
     - lint / baseline 无锚点时，把预测 Δ 里现存的非 Python、非文档、非声明、非测试文件放进 `pending`，`notes` 加「final 精确预测在 preflight」；
     - preflight 无锚点时，触发项是 `final:no-anchor`；
     - preflight 时基线有失败、但缺 `failed_nodes`，触发项是 `final:baseline-missing-failed-nodes`。
   - **设计边界**：非 pytest 的已识别运行器或部件形态 → 不全选，`notes` 加「final 恒全量（设计边界）」。
   - **库外**：`git rev-parse` 失败时，只按 owns 条目文件名判定全局文件，不取锚点。
   - **`_lint_scope` 的 builtin 分支**：摘要拼上 notes；把 `pending` 传给 `_scope_reason_errors`。
5. **解锁**：去掉 `tests/test_builtin_scope_precision.py` 7 条 xfail（护栏本来就没有标记），删掉不再使用的 `PENDING`。MUST NOT 改断言与函数名。
