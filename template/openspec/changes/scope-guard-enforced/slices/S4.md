# S4 · 安装器与文档：install.sh 调 scope-seed、本仓库声明 builtin、schema / 三个命令及同名 skill / README

## 做什么

- **新装与升级都种选测声明**：缺声明时由 S1 的 `scope-seed` 判定。
- **本仓库自己声明** `{"builtin": true}`。
- **文档同步契约 v2**：命令与同名 skill 同改，禁漂移。

规则原文见 `specs/install-scope-seed/spec.md`，决策见 `design.md` D11、D12。

## 怎么做

1. **`install.sh`**：在 openspec 种子循环（现 `:382`）之后、`--upgrade` 的 schemas 刷新之前或之后均可，两种模式都执行：
   - **有 python3**：`python3 "$TEMPLATE_SRC/.claude/hooks/slice-gate.py" scope-seed --openspec-root "$TARGET/openspec"`。用模板自带那一份，不用目标里可能过旧的脚本。
     - 输出逐行以 `[scope]` 前缀打印，沿用 `log_*` 风格，可新增 `log_scope`；
     - 首行含「已种」→ `ADD_COUNT+1`；
     - 「未种」时追加一段醒目提示：本仓库自带选测（字样「自带选测」），须实现只算范围的命令并写 `openspec/gate-scope.json` 的 `cmd`；在此之前新 change 的 lint 会判「未声明选测范围」。
   - **无 python3**：打印手动声明的指引，安装照常完成。
   - 不新增参数，不交互（ADR `DRAFT-installer-versioned-with-template` 决策 2）。
   - 结尾「更多」小节补一行：选测声明 `openspec/gate-scope.json`（builtin / cmd），以及契约 v2 的要点。
2. **`template/openspec/gate-scope.json`**：内容 `{"builtin": true}` 加换行。这是本仓库自己的声明（`template/openspec` 兼作本仓工作区）；安装器不拷贝它，目标仓库由 `scope-seed` 生成。
3. **`tests/test_install.py`**：
   - `test_fresh_install_ships_only_seeds` 的期望集合加上 `gate-scope.json`；
   - 去掉 4 条 S4 骨架的 xfail，删掉不再使用的 `PENDING_S4`；
   - 其它既有断言不变。
4. **文档**：
   - **schema**（`template/openspec/schemas/intent-driven/schema.yaml`）：tasks instruction 里的 `gate.scope` 段（现 `:302-311`）改写为契约 v2。须含：
     - `{"builtin": true}` / `{"cmd": …}` 二选一、优先级；
     - 未声明判红与伪触发项 `scope:undeclared`；
     - builtin 只配可识别的 `gate.test`；
     - `GATE_SCOPE_PLANNED`、`GATE_SCOPE_CHANGE`；
     - 内建提供方的预测与待定项；
     - baseline / final 开跑前复核、理由以 approve 提交为准。
   - **`/opsx-propose` + 同名 skill**（`opsx-propose.md:54` / `SKILL.md:62`）：仓库自带选测那一条改写为契约 v2，须含 `{"builtin": true}`、`GATE_SCOPE_PLANNED`、`GATE_SCOPE_CHANGE`、`scope:undeclared`，并保留现有的 `gate.scope`、`gate-scope.json`、`GATE_SCOPE_OUT`、`gate.scope_full_reason`（现有文档测试要求）。
   - **`/opsx-apply` + 同名 skill**：在 preflight 说明里加入范围复核；补一条 final「开跑前复核」：未表态的全选 → `G2 scope` 红、不跑测试，按「门禁红不收口」处理；`--full` 豁免。须含「开跑前复核」。
   - **`/opsx-verify` + 同名 skill**：「自动全量」一行的「依赖图没见过的非 Python 文件」补上两点：声明文件与 `.claude/**` 除外；shell 静态闭包算作触及。另补「开跑前复核」。⚠ 该行不得出现 `test-tiers.json`（现有测试要求）。
   - **README**：
     - 「何时全量」一行同 verify 的改法；
     - `gate.scope` / `gate-scope.json` 一条改写为契约 v2；
     - 安装说明补 `scope-seed` 的行为。
     - 须含 `{"builtin": true}`、`GATE_SCOPE_PLANNED`、「开跑前复核」、`scope-seed`。
5. **解锁**：去掉 `tests/test_scope_docs.py::test_docs_describe_scope_contract_v2` 的 xfail，删掉不再使用的 `PENDING_S4`。MUST NOT 改断言与函数名。
